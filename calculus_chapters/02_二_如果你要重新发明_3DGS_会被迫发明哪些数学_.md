# Ch02 - 如果你要重新发明 3DGS，会被迫发明哪些数学概念？

> **本章目标**：从"优化 Gaussian 参数以最小化 loss"这个单一目标出发，反向推导为什么需要导数、梯度、链式法则。  
> **核心理念**：不是"微积分很厉害所以用它"，而是"问题逼你必须用这些工具"。🔥

## 🎯 起点：你只有一个目标

假设你是 2023 年的研究者，面对这样的任务：

```python
# 给定
images = [img_1, img_2, ..., img_N]  # N 张带相机参数的照片
target = "生成一个 3D 表示，能渲染出 Novel View"

# 你选择用 Gaussian Splatting
class Gaussian:
    def __init__(self):
        self.mu = [x, y, z]          # 中心位置（9 自由度 per Gaussian）
        self.covariance = 3x3 matrix # 形状/旋转（6 自由度，对称正定）
        self.opacity = alpha         # 透明度（1 自由度）
        self.color = SH coeffs       # 颜色（4-64 自由度，SH 阶数决定）

# 问题：怎么从"随机初始化的 Gaussian"变成"能渲染出正确图像的 Gaussian"？
```

## 🔥 被迫发明 #1: "变化率" → **导数**

### 问题场景

你现在有 100,000 个 Gaussian，每个有 ~20-50 个参数。总共 **2M - 5M 自由度**。

**关键矛盾**：
> 你总不能对每个参数都"试一下往左调、再试一下往右调"吧？那要试多久？

### 被迫的洞察

假设某个参数 θ（比如第 k 个 Gaussian 的 x 坐标），loss 是它的函数 `L(θ)`：

```text
        L(θ)
          │
    高 ───┤      ╱╲
          │     ╱  ╲
    低 ───┼────╱────╰──→ θ
          │   A      B
```

**直觉**：在点 A，曲线"往上走"（θ增大 → loss 增大）。那应该往哪调？

### 导数的诞生

定义：**瞬时变化率** = `极限情况下的平均变化率`

$$\frac{dL}{dθ} = \lim_{h→0} \frac{L(θ+h) - L(θ)}{h}$$

**工程翻译**：
- `dL/dθ > 0` → θ增大会让 loss 变大 → **应该减小 θ**（往 `-gradient` 方向）
- `dL/dθ < 0` → θ增大会让 loss 变小 → **应该增加 θ**
- `dL/dθ = 0` → 可能是极值点（最优解？或者鞍点？）

### ✅ 第一个被迫结论

> **要优化参数，必须知道"每个参数的变化率"**  
> → 这就是为什么你需要**导数**。

---

## 🔥 被迫发明 #2: "多变量同时调" → **梯度向量**

### 问题场景

单个 Gaussian 的参数不是独立的！改变 μ（位置）会影响它投射到哪些像素；改变 α（透明度）会影响它在 alpha blending 中的权重。

**关键矛盾**：
> 如果只调一个参数，其他不动，效率太低。能不能"一次性知道所有参数的最优调整方向"？

### 被迫的洞察

定义：**偏导数** = "固定其他变量，只看这一个的变化率"

$$\frac{∂L}{∂μ_x} = \text{"当 μ_x 变化时 L 怎么变（假设 μ_y, μ_z, α, c...都固定）"}$$

把所有偏导数拼成一个向量：
$$∇_θ L(θ) = \begin{bmatrix} \frac{∂L}{∂μ_x} \\ \frac{∂L}{∂μ_y} \\ \frac{∂L}{∂μ_z} \\ \frac{∂L}{∂α} \\ \vdots \\ \frac{∂L}{∂c_{SH}} \end{bmatrix}$$

**关键性质**：梯度向量指向"上升最快的方向"，所以 `-∇L` 指向"下降最快的方向"。

### ✅ 第二个被迫结论

> **多参数联合优化需要知道每个参数的偏导数**  
> → 这就是为什么你需要**梯度向量**。

---

## 🔥 被迫发明 #3: "穿透渲染管线" → **链式法则**

### 问题场景

这是最关键的！render() 函数是黑盒：

```python
def render(gaussians, camera):
    # Step 1: 投影到 2D
    projected = [project(g, camera) for g in gaussians]
    
    # Step 2: 深度排序
    sorted_gaussians = sort_by_depth(projected)
    
    # Step 3: Alpha blending（逐像素）
    for pixel in image:
        color = (0, 0, 0)
        alpha_accum = 0
        for g in gaussians_contributing_to_this_pixel:
            t = (1 - alpha_accum) * g.opacity_2d
            color += t * g.color
            alpha_accum += t
        pixel.rgb = color
    
    return image
```

**关键矛盾**：
> 你想知道 `∂Loss/∂gaussian.mu`，但 Loss 和 mu 之间隔了投影 → 排序 → blending 三层函数！  
> **怎么办？**

### 被迫的洞察

假设最简单的嵌套：`L(f(g(θ)))`，想求 `dL/dθ`。

**链式法则**（一维版本）：
$$\frac{dL}{dθ} = \frac{dL}{df} · \frac{df}{dg} · \frac{dg}{dθ}$$

**工程翻译**：从 Loss 往回传，每一层"乘以这层的导数"。

扩展到多变量（矩阵形式）：
$$\frac{∂L}{∂θ_i} = \sum_{j,k,...} \frac{∂L}{∂o_j} · \frac{∂o_j}{∂h_k} · ... · \frac{∂u_m}{∂θ_i}$$

### 3DGS 中的链式法则路径

```text
Loss = MSE(rendered_img, ground_truth)
         ↓ ∂L/∂pixel_color (简单：就是误差本身)
pixel_color = alpha_blending(gaussians_2d)
         ↓ ∂color/∂(α_i, c_i) (alpha blending 的导数，解析可求！)
gaussian_2d = project_3D_to_2D(gaussian_3D)
         ↓ ∂(α_2d, c_2d)/∂(μ_3D, Σ_3D) (投影公式的导数，Jacobian 矩阵)
Loss 对 Gaussian 参数的梯度 ← DONE!
```

### ✅ 第三个被迫结论

> **渲染管线是嵌套函数 → 需要链式法则穿透它**  
> → 这就是为什么你需要**反向传播（backpropagation）**。

## 🔥 被迫发明 #4: "累积效应" → **积分**

### 问题场景

Volume Rendering Equation：
$$C(r) = \int_{t_n}^{t_f} T(t) · α(t) · c(t) dt, \quad T(t) = e^{-\int_0^t σ(s) ds}$$

**关键矛盾**：
> 光线穿过场景时，每个点的颜色都要"累积"。但积分是连续的，代码里只能离散求和。  
> **怎么从 `∫` 变成 `Σ`？**

### 被迫的洞察

数值积分的核心思想：**小区间上近似为常数**

$$\int_a^b f(t) dt ≈ \sum_{i=1}^N f(t_i^*) · Δt, \quad Δt = \frac{b-a}{N}$$

在 3DGS 中，每个 Gaussian 相当于一个"离散采样点"：
- `T_i` = 到第 i 个 Gaussian 的透射率（前面所有高斯的透明度累积）
- `(1 - e^{-σ_i δ_i})` ≈ α_i（这个高斯的不透明度）
- `c_i` = 这个高斯的颜色

离散版本：
$$C(r) ≈ \sum_{i=1}^N T_i · α_i · c_i, \quad T_i = \prod_{j<i} (1 - α_j)$$

### ✅ 第四个被迫结论

> **光线穿过场景是"累积效应"** → 自然导出积分形式  
> **但代码里只能用离散求和近似** → 这就是为什么你需要理解**数值积分**。

## 📊 总结：从问题到数学的映射表

| 工程问题 | 被迫发明的数学 | 3DGS 中的角色 |
|----------|----------------|--------------|
| "参数该往哪调？" | **导数** `df/dθ` | 单个参数的更新方向 |
| "多参数一起怎么调？" | **梯度向量** `∇f(θ)` | 所有参数的联合最速下降方向 |
| "渲染管线是黑盒，gradient 怎么穿过去？" | **链式法则** | 反向传播的核心 |
| "光线穿过场景的颜色怎么累积？" | **积分** → 离散求和 | Volume Rendering Equation |

## 🧠 深度练习 (Deep Practice)

### 1. Finite Difference — 为什么不够精确？
**问题**: 如果只有有限差分，为什么无法实现高效且精确的神经网络训练？

💡 **Hint**: 有限差分的步长选择与计算成本问题。

✅ **Answer**: 
1. **计算成本高**: 有限差分法需要为每个参数额外进行一次前向计算（Forward Pass）。如果有百万个参数，就需要百万次渲染，这完全不可行。
2. **精度陷阱**: 步长 $h$ 极难选择。太大导致误差大（截断误差）；太小受计算机浮点精度限制（舍入误差）。导数提供了无需试错的解析解。

---

### 2. Vector Space — 联合优化
**问题**: 为什么在多参数优化中，我们不能简单地逐个调整参数？

💡 **Hint**: 参数之间的耦合效应与空间方向。

✅ **Answer**: 
1. **核心逻辑**: Loss 表面是一个 $N$ 维曲面（如碗状）。
2. **直觉解释**: 如果只调 X 坐标而不动 Y 坐标，你只能沿着坐标轴走“之字形”路线，收敛极慢且效率低。梯度向量提供了**同时更新所有参数**的最优方向（最短路径下坡），这才是高效训练的关键。

---

### 3. Gradient Vector — 最优解
**问题**: Loss 是标量，但 Gradient 是向量。为什么我们要计算这个“超级向量”？

💡 **Hint**: 方向信息的完整性。

✅ **Answer**: 
1. **核心逻辑**: 标量只能告诉我们“当前误差有多大”，但不能告诉我们要往哪个维度移动最快。
2. **物理直觉**: 梯度是一个“导航仪”。它由所有偏导数组成，指向**最速上升方向**。取反后（$-
abla L$）就是最速下降方向，能让我们一步到达更优的状态。

---

### 4. Alpha Blending — 非线性来源
**问题**: 写出单像素 Alpha blending 的数学公式，并解释为什么它是非线性的？

💡 **Hint**: 乘积项导致非线性。

✅ **Answer**: 
1. **核心公式**: $C = c_1lpha_1 + c_2(1-lpha_1)lpha_2 + ...$
2. **直觉解释**: 包含透明度之间的乘法（如 $lpha_1 \cdot lpha_2$）。这意味着“前面的不透明度”会影响“后面的贡献率”。这种相互影响使得 Loss 对参数不再是简单的线性关系，增加了优化的难度。

---

### 5. Density vs Opacity — 映射转换
**问题**: 在连续 VRE 和离散 Gaussian Splatting 之间，不透明度 ($\sigma$) 是如何转换的？

💡 **Hint**: 体积密度到几何不透明度的映射。

✅ **Answer**: 
1. **核心公式**: $lpha = 1 - e^{-\sigma \delta}$ （其中 $\delta$ 是高斯厚度）。
2. **物理直觉**: 这是一个从“连续介质”到“离散物体”的转换。当密度很高时，$lpha$ 趋近于 1（完全不透明），符合物理直觉：东西太厚就看不见了。

### 6. Finite Difference Error — 截断误差
**问题**: 计算 $f(x)=x^3$ 在 $x=1$ 处的有限差分误差（取 $h=0.1$）。实际导数是多少？

💡 **Hint**: 对比解析解与近似值。

✅ **Answer**: 
1. **精确值**: $(x^3)' = 3x^2$，在 $x=1$ 处值为 **3**。
2. **近似值**: $rac{1.1^3 - 1^3}{0.1} = rac{1.331-1}{0.1} = 3.31$。
3. **结论**: 误差为 $0.31$。这证明了有限差分并不完美，且存在截断误差（由高阶项引起）。

### 7. Gradient Descent Proof — 几何直觉
**问题**: 简述“为什么负梯度方向是最速下降方向”的几何直觉证明过程。

💡 **Hint**: 利用点积公式 $
abla f \cdot d = |
abla f||d|\cos	heta$。

✅ **Answer**: 
1. **核心推导**: 泰勒展开给出 $\Delta L pprox 
abla f^T d = |
abla f||d|\cos	heta$。
2. **最优选择**: 要使 $\Delta L$ 最小（下降最快），必须让 $\cos	heta = -1$，即夹角为 $180^\circ$。这意味着步长方向与梯度方向完全相反。

### 8. Alpha Blending Order — 物理遮挡
**问题**: 为什么 Alpha blending 必须按照深度排序？

💡 **Hint**: 物理遮挡关系是累积的。

✅ **Answer**: 
1. **核心逻辑**: $T_i = \prod_{j < i} (1-lpha_j)$。前面的物体决定了光线是否能到达后面的物体。
2. **直觉解释**: 如果顺序乱了，后渲染的物体会错误地覆盖前渲染的物体（例如透视投影失效），导致视觉上的“穿帮”和错误的物理模拟。

### 9. Sensitivity Analysis — 梯度为零的含义
**问题**: 如果 Loss 对参数 $\mu$ 的偏导数接近零，说明模型处于什么状态？

💡 **Hint**: 已经收敛或该参数不起作用。

✅ **Answer**: 
1. **两种可能**: (1) 该高斯不在相机视锥内（Out-of-view），不参与渲染；(2) 参数 $\mu$ 已经调到了足够好的位置，处于局部极小值点。
3. **处理手段**: 对于第一种情况，梯度为零是正常的；对于第二种，模型认为不需要再动它了。

### 10. Jacobian in Rendering — 空间映射
**问题**: 在投影过程中，Jacobian 矩阵描述了输入和输出之间的什么变化？

💡 **Hint**: 空间位置的线性缩放与旋转。

✅ **Answer**: 
1. **核心逻辑**: 它是从 3D 坐标到 2D 像素坐标的导数映射。
2. **物理直觉**: 它告诉模型：“如果你在 X 方向移动 1 厘米，屏幕上哪个像素会发生变化？变化多大？”这是梯度能回到 3D 空间的基础。

### 11. Numerical Stability — 指数下溢
**问题**: 在计算 $e^{-x}$ 时，如果 $x$ 非常大（如 1000），会发生什么数值问题？如何解决？

💡 **Hint**: 下溢 (Underflow) 到 0。

✅ **Answer**: 
1. **现象**: 结果变成浮点数精度的极限值 0。
2. **后果**: 导致梯度消失（$T=0 \implies$ 后面全黑）。
3. **解决**: 确保 $\sigma \delta$ 不会过大，或在代码中使用数值稳定的函数形式。

### 12. Parameter Initialization — 起点选择
**问题**: 为什么初始的 Gaussian 参数设置很重要？它如何影响梯度下降的路径？

💡 **Hint**: 起点决定最终落入哪个“坑”。

✅ **Answer**: 
1. **核心逻辑**: 非凸 Loss 表面有许多局部最优值（坑）。
2. **直觉解释**: 如果初始化得太远或方向错误，模型可能一开始就陷入次优的谷底。好的初始化（如基于点云）能让我们从一个“有希望”的位置开始下坡。

### 13. Chain Rule Necessity — 嵌套函数
**问题**: 为什么我们不能直接写出 Loss 对 Gaussian 参数的导数公式？

💡 **Hint**: 中间变量的复杂性。

✅ **Answer**: 
1. **核心逻辑**: 渲染管线包含透视除法（非线性）、排序（离散操作）等复杂步骤。
2. **直觉解释**: 这些操作组合在一起极其复杂，几乎无法写出一个全局解析解。只有利用链式法则拆解成每一小步的导数，才能计算出总梯度。

### 14. Gradient Clipping — 防止爆炸
**问题**: 什么是梯度裁剪 (Gradient Clipping)？为什么它在训练初期非常必要？

💡 **Hint**: 限制梯度的最大范数以防止爆炸。

✅ **Answer**: 
1. **核心逻辑**: 当 $\|
abla L\|$ 超过阈值（如 $0.01$）时，按比例缩小所有梯度。
2. **直觉解释**: 初始阶段 Loss 很大且梯度可能极大（如 1000+）。不裁剪的话，一次更新就会把参数推到无穷大导致数值崩溃。

### 15. Adaptive Optimizers — Adam 优势
**问题**: 对比 SGD 和 Adam：为什么 Adam 在处理稀疏梯度时表现更好？

💡 **Hint**: 自适应学习率与动量机制。

✅ **Answer**: 
1. **核心逻辑**: SGD 使用全局统一的固定步长；Adam 根据历史梯度的二阶矩为每个参数独立调整步长。
2. **直觉解释**: 如果一个参数很久没更新（稀疏），它的“惯性”积累少，步长会变大，能更快地被激活；而频繁更新的参数步长会自动缩小以保持稳定。

1. **核心代码**: 直接访问 tensor 的 `.grad` 属性（例如 `param.grad`）。
2. **物理直觉**: 它存储了链式法则反向传播计算出的最终导数值，是模型“学习”到的反馈信号。

### 18. Loss Landscape — 下山直觉
**问题**: 想象 Loss 表面是一个满是坑洼的山地地形，梯度下降法是如何“下山”的？

💡 **Hint**: 局部下坡策略。

✅ **Answer**: 
1. **核心逻辑**: 它不关心全局哪里最低（全知视角），只关心脚下哪块坡度最陡（局部视角）。
2. **直觉解释**: 只要一直往最陡的下坡走，最终总能到达某个坑底（局部最优解）。这就是为什么我们不需要知道整个函数的公式。

### 19. Transmittance & Gradient — VRE 导数
**问题**: 在 VRE 中，如果 $T(t)$（透射率）趋近于 0，会对 $rac{\partial L}{\partial \sigma}$ 产生什么影响？

💡 **Hint**: 梯度消失。

✅ **Answer**: 
1. **核心逻辑**: 反向传播公式中包含因子 $T(t)$。
2. **直觉解释**: 如果前面的高斯挡住了光（$T=0$），Loss 对后面高密度 $\sigma$ 的导数也变成 0。模型无法知道“如果把后面的密度调大，有没有用”，因为反正都看不见。**这就是梯度消失**。

### 20. Sigmoid Gradient — 饱和区
**问题**: 为什么 Sigmoid 函数在接近 0 和 1 时梯度会变得很小？

💡 **Hint**: 曲线斜率的变化。

✅ **Answer**: 
1. **推导结果**: $\sigma'(x) = \sigma(x)(1-\sigma(x))$。
2. **直觉解释**: 当 $x$ 很大或很小时，$\sigma(x)$ 趋于常数（0 或 1），斜率变为水平线（导数为 0）。这导致反向传播信号极弱（梯度消失）。
