# Ch02 - 如果你要重新发明 3DGS，会被迫发明哪些数学概念？

> **本章目标**：从"优化 Gaussian 参数以最小化 loss"这个单一目标出发，反向推导为什么需要导数、梯度、链式法则。  
> **核心理念**：不是"微积分很厉害所以用它"，而是"问题逼你必须用这些工具"。🔥

---

## 🎯 起点：你只有一个目标

假设你是 2023 年的研究者，面对这样的任务：

```python
# 给定
images = [img_1, img_2, ..., img_N]  # N 张带相机参数的照片
target = "生成一个 3D 表示，能渲染出 Novel View"

# 你选择用 Gaussian Splatting
class Gaussian:
    def __init__(self):
        self.mu = [x, y, z]          # 中心位置（9 自由度 per Gaussian）
        self.covariance = 3x3 matrix # 形状/旋转（6 自由度，对称正定）
        self.opacity = alpha         # 透明度（1 自由度）
        self.color = SH coeffs       # 颜色（4-64 自由度，SH 阶数决定）

# 问题：怎么从"随机初始化的 Gaussian"变成"能渲染出正确图像的 Gaussian"？
```

---

## 🔥 被迫发明 #1: "变化率" → **导数**

### 问题场景

你现在有 100,000 个 Gaussian，每个有 ~20-50 个参数。总共 **2M - 5M 自由度**。

**关键矛盾**：
> 你总不能对每个参数都"试一下往左调、再试一下往右调"吧？那要试多久？

### 被迫的洞察

假设某个参数 θ（比如第 k 个 Gaussian 的 x 坐标），loss 是它的函数 `L(θ)`：

```text
        L(θ)
          │
    高 ───┤      ╱╲
          │     ╱  ╲
    低 ───┼────╱────╰──→ θ
          │   A      B
```

**直觉**：在点 A，曲线"往上走"（θ增大 → loss 增大）。那应该往哪调？

### 导数的诞生

定义：**瞬时变化率** = `极限情况下的平均变化率`

$$\frac{dL}{dθ} = \lim_{h→0} \frac{L(θ+h) - L(θ)}{h}$$

**工程翻译**：
- `dL/dθ > 0` → θ增大会让 loss 变大 → **应该减小 θ**（往 `-gradient` 方向）
- `dL/dθ < 0` → θ增大会让 loss 变小 → **应该增加 θ**
- `dL/dθ = 0` → 可能是极值点（最优解？或者鞍点？）

### ✅ 第一个被迫结论

> **要优化参数，必须知道"每个参数的变化率"**  
> → 这就是为什么你需要**导数**。

---

## 🔥 被迫发明 #2: "多变量同时调" → **梯度向量**

### 问题场景

单个 Gaussian 的参数不是独立的！改变 μ（位置）会影响它投射到哪些像素；改变 α（透明度）会影响它在 alpha blending 中的权重。

**关键矛盾**：
> 如果只调一个参数，其他不动，效率太低。能不能"一次性知道所有参数的最优调整方向"？

### 被迫的洞察

定义：**偏导数** = "固定其他变量，只看这一个的变化率"

$$\frac{∂L}{∂μ_x} = \text{"当 μ_x 变化时 L 怎么变（假设 μ_y, μ_z, α, c...都固定）"}$$

把所有偏导数拼成一个向量：
$$∇_θ L(θ) = \begin{bmatrix} \frac{∂L}{∂μ_x} \\ \frac{∂L}{∂μ_y} \\ \frac{∂L}{∂μ_z} \\ \frac{∂L}{∂α} \\ \vdots \\ \frac{∂L}{∂c_{SH}} \end{bmatrix}$$

**关键性质**：梯度向量指向"上升最快的方向"，所以 `-∇L` 指向"下降最快的方向"。

### ✅ 第二个被迫结论

> **多参数联合优化需要知道每个参数的偏导数**  
> → 这就是为什么你需要**梯度向量**。

---

## 🔥 被迫发明 #3: "穿透渲染管线" → **链式法则**

### 问题场景

这是最关键的！render() 函数是黑盒：

```python
def render(gaussians, camera):
    # Step 1: 投影到 2D
    projected = [project(g, camera) for g in gaussians]
    
    # Step 2: 深度排序
    sorted_gaussians = sort_by_depth(projected)
    
    # Step 3: Alpha blending（逐像素）
    for pixel in image:
        color = (0, 0, 0)
        alpha_accum = 0
        for g in gaussians_contributing_to_this_pixel:
            t = (1 - alpha_accum) * g.opacity_2d
            color += t * g.color
            alpha_accum += t
        pixel.rgb = color
    
    return image
```

**关键矛盾**：
> 你想知道 `∂Loss/∂gaussian.mu`，但 Loss 和 mu 之间隔了投影 → 排序 → blending 三层函数！  
> **怎么办？**

### 被迫的洞察

假设最简单的嵌套：`L(f(g(θ)))`，想求 `dL/dθ`。

**链式法则**（一维版本）：
$$\frac{dL}{dθ} = \frac{dL}{df} · \frac{df}{dg} · \frac{dg}{dθ}$$

**工程翻译**：从 Loss 往回传，每一层"乘以这层的导数"。

扩展到多变量（矩阵形式）：
$$\frac{∂L}{∂θ_i} = \sum_{j,k,...} \frac{∂L}{∂o_j} · \frac{∂o_j}{∂h_k} · ... · \frac{∂u_m}{∂θ_i}$$

### 3DGS 中的链式法则路径

```text
Loss = MSE(rendered_img, ground_truth)
         ↓ ∂L/∂pixel_color (简单：就是误差本身)
pixel_color = alpha_blending(gaussians_2d)
         ↓ ∂color/∂(α_i, c_i) (alpha blending 的导数，解析可求！)
gaussian_2d = project_3D_to_2D(gaussian_3D)
         ↓ ∂(α_2d, c_2d)/∂(μ_3D, Σ_3D) (投影公式的导数，Jacobian 矩阵)
Loss 对 Gaussian 参数的梯度 ← DONE!
```

### ✅ 第三个被迫结论

> **渲染管线是嵌套函数 → 需要链式法则穿透它**  
> → 这就是为什么你需要**反向传播（backpropagation）**。

## 🔥 被迫发明 #4: "累积效应" → **积分**

### 问题场景

Volume Rendering Equation：
$$C(r) = \int_{t_n}^{t_f} T(t) · α(t) · c(t) dt, \quad T(t) = e^{-\int_0^t σ(s) ds}$$

**关键矛盾**：
> 光线穿过场景时，每个点的颜色都要"累积"。但积分是连续的，代码里只能离散求和。  
> **怎么从 `∫` 变成 `Σ`？**

### 被迫的洞察

数值积分的核心思想：**小区间上近似为常数**

$$\int_a^b f(t) dt ≈ \sum_{i=1}^N f(t_i^*) · Δt, \quad Δt = \frac{b-a}{N}$$

在 3DGS 中，每个 Gaussian 相当于一个"离散采样点"：
- `T_i` = 到第 i 个 Gaussian 的透射率（前面所有高斯的透明度累积）
- `(1 - e^{-σ_i δ_i})` ≈ α_i（这个高斯的不透明度）
- `c_i` = 这个高斯的颜色

离散版本：
$$C(r) ≈ \sum_{i=1}^N T_i · α_i · c_i, \quad T_i = \prod_{j<i} (1 - α_j)$$

### ✅ 第四个被迫结论

> **光线穿过场景是"累积效应"** → 自然导出积分形式  
> **但代码里只能用离散求和近似** → 这就是为什么你需要理解**数值积分**。

---

## 📊 总结：从问题到数学的映射表

| 工程问题 | 被迫发明的数学 | 3DGS 中的角色 |
|----------|----------------|--------------|
| "参数该往哪调？" | **导数** `df/dθ` | 单个参数的更新方向 |
| "多参数一起怎么调？" | **梯度向量** `∇f(θ)` | 所有参数的联合最速下降方向 |
| "渲染管线是黑盒，gradient 怎么穿过去？" | **链式法则** | 反向传播的核心 |
| "光线穿过场景的颜色怎么累积？" | **积分** → 离散求和 | Volume Rendering Equation |

## 🧠 深度练习 (Deep Practice)

### 1.Forced Invention
**问题**: 如果只有有限差分（Finite Difference），为什么无法实现精确的神经网络训练？

💡 **Hint**: 有限差分的步长选择问题。

✅ **Answer**: 有限差分需要两次前向计算，且步长 $h$ 的选择极难：太大误差大（截断误差），太小精度丢失（舍入误差）。导数提供了无需试错的解析解。

---
### 2.Gradient Vector Space
**问题**: 为什么在多参数优化中，我们不能简单地逐个调整参数？

💡 **Hint**: 参数之间的耦合效应。

✅ **Answer**: 因为参数空间是 $N$ 维的。改变一个参数可能改变了其他参数的有效贡献范围（例如位置改变导致高斯遮挡关系变化）。我们需要同时更新所有参数以到达最低点。

---
### 3.Vector vs Scalar
**问题**: Loss 是标量，但 Gradient 是向量。为什么我们要计算这个“超级向量”？

💡 **Hint**: 方向信息的完整性。

✅ **Answer**: 因为 Loss 只有一个值，它无法告诉我们该往哪个维度移动最快。梯度向量提供了每一个维度上的“坡度”，让我们能合成出下降最快的总方向。

---
### 4.Optimal Step Size
**问题**: 在梯度下降中，如果学习率 $\eta$ 设置得过大，会发生什么？如果过小呢？

💡 **Hint**: 步长与收敛速度/震荡的关系。

✅ **Answer**: 过大：更新幅度超过谷底，导致 Loss 震荡甚至发散（爆炸）；过小：迭代次数过多，训练时间极长，容易陷入次优的平坦区域。

---
### 5.Alpha Blending Math
**问题**: 写出单像素 Alpha blending 的数学公式 $C = \sum c_i \alpha_i \prod (1-\alpha_j)$。解释为什么它是非线性的？

💡 **Hint**: 乘积项导致非线性。

✅ **Answer**: 因为包含透明度 $lpha$ 之间的乘法运算（如 $lpha_1 \cdot lpha_2$）。这使得 Loss 对 $lpha$ 的导数不再是简单的常数，而是依赖于其他高斯的当前状态。

---
### 6.Density vs Opacity
**问题**: 在连续 VRE 和离散 Gaussian Splatting 之间，不透明度 ($\sigma$) 是如何转换的？

💡 **Hint**: 体积密度到几何不透明度的映射。

✅ **Answer**: 通过公式 $lpha = 1 - e^{-\sigma \delta}$ 进行转换。当密度 $\sigma$ 很大时，$lpha$ 趋近于 1；当 $\delta$（采样间距）很小时，离散求和逼近连续积分。

---
### 7.Finite Difference Error
**问题**: 计算 $f(x)=x^3$ 在 $x=1$ 处的有限差分误差（取 $h=0.1$）。实际导数是多少？

💡 **Hint**: 对比解析解与近似值。

✅ **Answer**: 精确导数是 $3(1)^2 = 3$。近似值是 $rac{1.1^3 - 1}{0.1} = rac{1.331-1}{0.1} = 3.31$。误差为 $0.31$，这是由截断误差（高阶项）引起的。

---
### 8.Gradient Descent Proof
**问题**: 简述“为什么负梯度方向是最速下降方向”的几何直觉证明过程。

💡 **Hint**: 利用点积公式 $
abla f \cdot d = |
abla f||d|\cos	heta$。

✅ **Answer**: 当步长固定时，要使函数变化量最小（下降最快），$\cos	heta$ 必须取 $-1$，即方向与梯度完全相反。

---
### 9.Chain Rule Necessity
**问题**: 为什么我们不能直接写出 Loss 对 Gaussian 参数的导数公式？

💡 **Hint**: 中间变量的复杂性。

✅ **Answer**: 因为渲染管线包含大量非线性的嵌套操作（透视投影、排序）。Loss 是这些操作的复合函数，只有利用链式法则才能逐层剥离计算梯度。

---
### 10.Parameter Initialization
**问题**: 为什么初始的 Gaussian 参数设置很重要？它如何影响梯度下降的路径？

💡 **Hint**: 起点决定最终落入哪个“坑”。

✅ **Answer**: 非凸的 Loss 表面有许多局部最优值（坑）。如果初始化得太远或方向错误，模型可能陷入次优的谷底，无法达到最佳渲染质量。

---
### 11.Jacobian in Rendering
**问题**: 在投影过程中，Jacobian 矩阵描述了输入和输出之间的什么变化？

💡 **Hint**: 空间位置的线性缩放与旋转。

✅ **Answer**: 3D 坐标到 2D 屏幕坐标的映射是一个仿射变换（或透视除法）。Jacobian 描述了 3D 点的微小位移如何放大/缩放到 2D 图像平面上。

---
### 12.Numerical Stability
**问题**: 在计算 $e^{-x}$ 时，如果 $x$ 非常大（如 1000），会发生什么数值问题？如何解决？

💡 **Hint**: 下溢 (Underflow) 到 0。

✅ **Answer**: 结果会变成浮点数精度极限的 0。在 3DGS 中这会导致梯度消失。解决方法是确保 opacity 初始化合理，或使用 $\log(1-lpha)$ 等稳定计算形式。

---
### 13.Sensitivity Analysis
**问题**: 如果 Loss 对参数 $\mu$ 的偏导数接近零，说明模型处于什么状态？

💡 **Hint**: 已经收敛或该参数不起作用。

✅ **Answer**: 说明 $\mu$ 已经调整到了“足够好”的位置（局部极小值），或者该高斯不在相机视锥内（不参与渲染），因此没有梯度信号传回。

---
### 14.Volume Rendering Integral
**问题**: 如果场景中没有半透明物体，全是实心球体，VRE 积分公式还能用吗？

💡 **Hint**: 它是更通用的物理描述。

✅ **Answer**: 可以用。实心球体相当于 $\sigma$ (密度) 在内部极大、外部为 0 的特殊情况。积分依然有效，只是不透明度会瞬间从 0 跳到 1。

---
### 15.Gradient Clipping
**问题**: 什么是梯度裁剪 (Gradient Clipping)？为什么它在训练初期非常必要？

💡 **Hint**: 限制梯度的最大范数以防止爆炸。

✅ **Answer**: 初始阶段 Loss 很大且梯度可能极大（如 1000+）。不裁剪的话，一次更新就会把参数推到无穷大。裁剪能强制步长在安全范围内。

---
### 16.Adaptive Optimizers
**问题**: 对比 SGD 和 Adam 优化器：为什么 Adam 在处理稀疏梯度时表现更好？

💡 **Hint**: 自适应学习率与动量机制。

✅ **Answer**: SGD 使用全局统一的固定学习率。Adam 会根据历史梯度为每个参数独立调整步长（二阶矩估计），这对于某些参数很久才更新一次的场景非常有效。

---
### 17.Chain Rule in Code
**问题**: 在 PyTorch 中，调用 `loss.backward()` 后，如何获取某个特定参数的梯度？

💡 **Hint**: `.grad` 属性。

✅ **Answer**: 直接访问该 tensor 的 `.grad` 属性即可（例如 `param.grad`）。它存储了链式法则反向传播计算出的最终导数值。

---
### 18.Alpha Blending Order
**问题**: 为什么 Alpha blending 必须按照深度（从前到后或从后到前）排序？

💡 **Hint**: 物理遮挡关系是累积的。

✅ **Answer**: 如果顺序乱了，就会发生“前面的物体被后面的渲染覆盖”这种物理上不可能的现象。正确的排序保证了透明度 $T(t)$ 的正确计算。

---
### 19.Numerical Differentiation Code
**问题**: 编写一段 Python 代码，模拟通过有限差分法估算 $f(x)=x^3$ 在 $x=2$ 处的导数（取 $h=10^{-5}$）。

💡 **Hint**: 差商公式实现。

✅ **Answer**: `d = ( (2+1e-5)**3 - 2**3 ) / 1e-5`，结果应接近精确值 12.0。这展示了计算机如何通过极小的 $\Delta x$ 逼近导数定义。

---
### 20.Loss Landscape Intuition
**问题**: 想象 Loss 表面是一个满是坑洼的山地地形，梯度下降法是如何“下山”的？

💡 **Hint**: 局部下坡策略。

✅ **Answer**: 它不关心全局哪里最低，只关心脚下哪块坡度最陡（负梯度方向）。只要一直往最陡的下坡走，最终总能到达某个坑底（局部最优解）。
