# Ch03 - 导数：Newton 的炮弹与 Leibniz 的无穷小

> **本章目标**：回到 1665-1684 年，看 Newton 和 Leibniz 如何被同一个问题逼到墙角 —— "瞬时速度到底怎么算？"——然后各自发明了一个我们今天叫「导数」的工具。
> **核心洞察**：`loss.backward()` 的本质，就是两百年前他们发明的「变化率探测器」。

---

## 🔥 Part 0: 一个让两个天才头疼了 20 年的问题

### Newton 在隔离期盯着炮弹想的问题

1665年，剑桥大学因瘟疫关闭。23岁的 Isaac Newton 回到乡下隔离了两年（The Annus Mirabilis）。就是这段时间，他几乎单枪匹马发明了微积分。

他盯着一枚炮弹飞行，问了个看起来很简单的问题：

> **"这一瞬间（某个精确时刻），它的速度是多少？"**

听起来 trivial？但你仔细想——这其实是个逻辑死胡同。

---

### 为什么这个问题无解？（用当时的知识）

速度 = 位移 / 时间。这是 Newton 时代的定义，也是常识。

**平均速度**：
$$v_{\text{avg}} = \frac{\Delta x}{\Delta t} = \frac{x(t_0 + \Delta t) - x(t_0)}{\Delta t}$$

这个没问题 —— 你取一段有限时间 Δt，算位移差，除以时间。但问题出在「瞬时」：

**瞬时速度**要求 **Δt → 0**（精确到那个时间点）。

可一旦 Δt = 0：
$$v_{\text{instant}} = \frac{\Delta x}{0} \quad ??? $$

由于 Δt=0，位移 Δx 也必然为 0。我们得到了数学上最讨厌的东西：**$0/0$**（未定式）。

Newton 的困境：**物理直觉说"速度在每一刻都有确定的值"，但当时没有数学工具能计算它。** 🤯

---

### Newton 的破局思路：极限（Limits）

他的洞察很朴素（但也极其深刻）：

> **不要问"Δt=0 时速度是多少"。问"当 Δt 越来越小时，平均速度趋近于什么？"**

也就是取极限：
$$v(t_0) = \lim_{\Delta t \to 0} \frac{x(t_0 + \Delta t) - x(t_0)}{\Delta t}$$

**关键思维转变**：不直接算零，而是看「趋近过程中的稳定值」。当 Δt 从 1 → 0.1 → 0.01...，平均速度的数值会收敛到一个固定数字 —— **那个数字就是瞬时速度**。

---

### 用 Python 模拟 Newton 的困惑（跑一下你就懂了）

```python
def position(t): return -4.9*t**2 + 20*t  # 炮弹轨迹（抛物线）

t0 = 1.0  # 我们想知道 t=1 这一刻的速度
ds = [1, 0.5, 0.2, 0.1, 0.05, 0.01, 0.001]

print(f"在 t={t0} 时，瞬时速度趋近于：")
for dt in ds:
    avg_v = (position(t0 + dt) - position(t0)) / dt
    print(f"  Δt={dt:>7.3f} → 平均速度 v_avg = {avg_v:.4f}")

# 输出会看到数值稳定在 ~10.2...（其实就是 f'(1)）
```

**你看到了什么？** 当 Δt 越来越小，结果趋近于一个固定值。这个极限就是 **Newton 发明的「流数」（fluxion）** —— 也就是我们说的导数。

## 🔥 Part 1: Leibniz 的另一种视角 — 无穷小的符号魔法

几乎同一时期（1670s），德国哲学家 Gottfried Wilhelm Leibniz 独立发明了微积分。他的思路完全不同——而且更接近现代工程师的思维。

### Leibniz 的问题意识：他不想用"极限"这种哲学化的语言

Leibniz 是个实用主义者。他认为：

> **为什么不能把 dx 当作一个「无限小的变化量」来操作？**

在 Newton 那里，dx 是「趋近过程中的中间变量」。但在 Leibniz 眼里，**dx 就是存在的东西** —— 它比任何正数都小，但又不等于零。这就是「无穷小量」（infinitesimal）。

### Leibniz 的符号直觉：忽略高阶项

他从最简单的例子开始推导：假设 y = x²。

如果 x 变化了一个无穷小量 dx，那么 y 会变化多少？
$$y + dy = (x + dx)^2 = x^2 + 2x·dx + (dx)^2$$

两边减去 y = x²：
$$dy = 2x·dx + (dx)^2$$

**关键洞察**：(dx)² 是「无穷小的平方」——比 dx 还要小得多！在 Leibniz 的直觉中，它可以被忽略（modern math: 它是 $o(dx)$，高阶无穷小）。

所以：
$$dy = 2x·dx \quad\implies\quad \frac{dy}{dx} = 2x$$

**他直接把 dy/dx 当作一个分数来操作！** 不是极限，不是趋近 —— 就是 dy 除以 dx。这种符号代数化，让微积分变成了可计算的工程工具。

---

### Newton vs Leibniz：两种哲学，同一个数学

| | Newton（流数） | Leibniz（无穷小符号） |
|--|--|--|
| **思维方式** | 极限 / 趋近过程 | 无穷小量 / 代数操作 |
| **符号** | $\dot{x}$ （点表示时间变化率） | $dy/dx$（微分之比） |
| **直觉** | "Δt→0 时平均速度的极限" | "dy 和 dx 都是极小的，它们的比值有意义" |
| **对现代的影响** | 分析学严格化（ε-δ 语言） | 计算规则系统化（正是 autograd 的哲学！） |

---

### 🔥 Ember 的关键洞察

> **PyTorch 的 `autograd` 本质上是 Leibniz 派！**
> 
> PyTorch 不"算极限"。它做的是：追踪每个操作，把 dy 和 dx 的关系写成代数规则（dy = f'(x)·dx），然后链式相乘。这和 Leibniz 的符号操作哲学一模一样 —— **无穷小量之间的比例关系**。
> 
> Newton 的极限保证了严谨性，但 Leibniz 的符号给了工程实现。

## 🔥 Part 2: 几何直觉 — 切线的斜率（Newton's Geometric View）

如果你画 $f(x)$ 的曲线：
- **割线**（连接 x₀ 和 x₀+h）→ 它的斜率 = $\frac{f(x_0+h)-f(x_0)}{h}$ → Newton 的平均速度
- **当 h→0**，割线变成**切线** → 切线的斜率 = $f'(x_0)$

```text
        f(x)
          │
     (3,9)│       ╱───────→ 割线（h=1），斜率=(9-4)/1=5
          │      ╱
     (2,4)│    ╱ C → 切点 ←←← Newton 的"瞬时"
          │   ╱ ╲
          │  ╱   ╲────→ 切线（h→0），斜率=f'(2)=4
          │ ╱
          └─╫──────────→ x
            ②
```

**关键直觉**：导数 $f'(x_0)$ = **函数曲线在 x₀ 处的"陡度"**。

- $f'(x_0) > 0$ → 曲线在此处往上走（上坡）
- $f'(x_0) < 0$ → 曲线在此处往下走（下坡）  
- $f'(x_0) = 0$ → 切线水平 → 可能是极值点（谷底或峰顶，即驻点）

---

### ✅ 第一个关键结论（从 Newton/Leibniz 的困境中被迫推出）

> **如果你想知道"某个变量变化时结果怎么变"，你需要导数。**
> 
> - Newton 用它算炮弹瞬时速度
> - Leibniz 用它做代数推导
> - **你在 3DGS 里用它知道参数该往哪个方向调**

## 🔥 Part 3: 回到 3DGS — 导数是参数的导航仪

### 场景：训练循环中的"决策时刻"

```python
for step in range(30000):
    rendered_img = render(gaussians, camera)     # 前向渲染
    loss = L1(rendered_img, ground_truth)         # 计算差距
    
    # 🔥 这里是导数登场！
    loss.backward()       # ←←← 对每个参数 θ_i，算出 ∂L/∂θ_i
    optimizer.step()      # ←←← 用梯度更新：θ_i = θ_i - η·(∂L/∂θ_i)
```

**`loss.backward()` 在做什么？** 它本质上是在回答 Newton 的问题 —— "如果我微调这个参数，loss 会怎么变化？"

---

### 具体例子：Gaussian 中心的 x 坐标 μₓ

假设 `∂L/∂μₓ = +0.5`。

**Newton 视角解读**：
> "当 μₓ 增加时，loss 以每单位 0.5 的速率增大。所以为了减小 loss —— **应该减小 μₓ**！"

**Leibniz 视角解读**：
> $dL = \frac{∂L}{∂μₓ} · dμₓ$。如果我们要让 dL < 0（loss 下降），且 ∂L/∂μₓ > 0，那么必须取 dμₓ < 0（减小 μₓ）。

**梯度下降更新规则**：
$$\mu_x^{\text{new}} = \mu_x^{\text{old}} - \eta \cdot \frac{∂L}{∂\mu_x}$$

其中 $\eta > 0$ 是学习率（控制步长）。注意那个减号 —— **永远沿着导数的反方向走**。

---

### 为什么"反方向"是对的？（Newton 会点头）

```
    Loss
      │        ╱╲
高 ───┤       ╱  ╲
      │      ╱    ╰→ x (参数)
低 ───┼─────╱
      │   ·← 你在这里，梯度 > 0（往右走 loss 增大）
      └────────────→ 

结论：应该往左走！← = -gradient ✅
```

**导数的符号告诉你方向，大小告诉你"陡度有多高"**。这就是导航仪的工作原理。

## 🔥 Part 4: 常见导数速查表（Newton/Leibniz 的计算规则）

### 基础规则（记住这 6 个，覆盖 90% 的 3DGS 场景）

| 函数 $f(x)$ | 导数 $f'(x)$ | Leibniz 操作思路 | 3DGS 中的例子 |
|-----------|------------|-----------------|--------------|
| $x^n$ | $n \cdot x^{n-1}$ | $(x+dx)^n \approx x^n + nx·dx$ | MSE loss: $(p-t)² \to 2(p-t)$ |
| $e^x$ | $e^x$ | $d(e^x) = e^x·dx$（指数不变！） | alpha blending 的 `exp(-σδ)` |
| $\ln(x)$ | $1/x$ | $d(\ln x) = dx/x$ | KL divergence 正则化项 |
| $\sin(x)$ | $\cos(x)$ | 从无穷小三角形推导 | SH 球谐函数（view-dependent） |
| $f(g(x))$ | $f'(g)·g'$ | Leibniz 链式：$\frac{df}{dx} = \frac{df}{dg}\frac{dg}{dx}$ | **渲染管线的每一层** ⭐ |
| $af+bg$ | $a f' + b g'$ | 微分是线性的：$d(af) = a·df$ | L1 loss + λ·SSIM → 梯度加权求和 |

## 🔥 Part 5: Newton/Leibniz 的遗产 — 如何理解 autograd

### PyTorch 的 `backward()` 是 Leibniz 哲学的工程实现

```
┌───────────────────────────────────────────────┐
│          Leibniz (1670s)         PyTorch      │
│              │                       │        │
│  y = x²                │               │       │
│  dy = 2x·dx             │           torch.tensor│
│  dy/dx = 2x             │            requires_  │
│                         │            grad=True   │
│                        │               │        │
│                      backward()          │       │
│              对每个操作记录：              │       │
│                "这个操作的导数规则"         │       │
│                                       │       │
│           ∂L/∂x = (∂L/∂y) · (dy/dx)    │       │
└───────────────────────────────────────────────┘
```

**Leibniz 当年没法做的事**：自动追踪成百上千个操作的复合关系。

**PyTorch 今天做的事**：把每个操作（加法、乘法、exp、softmax...）的 Leibniz 规则编码为 C++，然后自动构建计算图、反向传播导数。**本质上就是两百年前的符号微分，但自动化了。**

**3.1 Newton 直觉题 — 理解极限思维**

设 $f(x) = x^2$。用 Newton 的方法算 $f'(3)$：

(a) 计算 $\Delta t = 1, 0.1, 0.01, 0.001$ 时的平均变化率：
$$\frac{f(3 + \Delta t) - f(3)}{\Delta t}$$

(b) 你看到了什么趋势？这个极限值是多少？（手算验证：$(x^2)' = 2x$，在 x=3 时应为多少？）

<details>
<summary>💡 提示</summary>
代入数值计算即可。注意当 $\Delta t \to 0$ 时，结果应该趋近于一个固定值。然后用代数推导验证：$(x+h)^2 - x^2 = 2xh + h^2$，除以 h 后取极限得到 $2x$。
</details>

<details>
<summary>✅ 参考答案</summary>
(a) 
- $\Delta t=1$: $(9-4)/1 = 5$
- $\Delta t=0.1$: $(4.84-4)/0.1 = 4.84$
- $\Delta t=0.01$: $(4.0804-4)/0.01 = 4.804$
- $\Delta t=0.001$: $(4.008004-4)/0.001 = 4.8004$

(b) 趋势：趋近于 **6**。手算验证：$(x^2)' = 2x$，在 $x=3$ 时 $f'(3) = 2 \cdot 3 = 6$ ✅
</details>

---

**3.2 Leibniz 符号练习 — 用无穷小量推导导数**

设 $f(x) = x^3$。用 Leibniz 的无穷小方法求 $f'(x)$：

(a) $(x + dx)^3 = x^3 + 3x^2·dx + 3x·(dx)^2 + (dx)^3$
(b) 忽略 $(dx)^2$ 和 $(dx)^3$（它们是高阶无穷小），得到 $dy \approx ?$
(c) $\frac{dy}{dx} = ?$

<details>
<summary>💡 提示</summary>
按步骤展开，像 Leibniz 那样忽略高阶项。
</details>

<details>
<summary>✅ 参考答案</summary>
(a) $(x+dx)^3 = x^3 + 3x^2·dx + 3x(dx)^2 + (dx)^3$
(b) $dy = (x+dx)^3 - x^3 \approx 3x^2·dx$（忽略高阶无穷小）
(c) $\frac{dy}{dx} = 3x^2$ → $(x^3)' = 3x^2$ ✅
</details>

**3.3 3DGS 关联 — 导数的符号直觉**

在训练一个 Gaussian 时，`backward()` 算出：
$$\frac{∂L}{∂\mu_x} = -0.4, \quad \frac{∂L}{∂\alpha} = +0.2$$

(a) $\mu_x$ 应该增大还是减小？为什么？
(b) $\alpha$（透明度）应该调大还是调小？哪个参数的"变化率绝对值更大"，意味着它对 loss 的影响更敏感？
(c) 用梯度下降公式写出更新：$\mu_x^{\text{new}} = \mu_x - \eta \cdot (-0.4)$。注意那个双重符号 —— 化简后是加还是减？

<details>
<summary>✅ 参考答案</summary>
(a) $\partial L/\partial\mu_x < 0$ → μₓ 增大时 loss 减小 → **应该增大 μₓ**（往正方向调）
(b) α：$\partial L/\partial\alpha > 0$ → α 增大会让 loss 增大 → **应该减小透明度**。|−0.4| = 0.4 > |0.2| = 0.2，所以 **μₓ 对 loss 更敏感**（变化率更大），调整 μₓ 的效果会比调整 α 更明显。
(c) $\mu_x^{\text{new}} = \mu_x - \eta·(-0.4) = \mu_x + 0.4\eta$ → **增大**。双重负号抵消，这是合理的（因为导数是负的，我们要走反方向 = 正方向）。
</details>

### 🔥 进阶题（选做）

**3.4 Newton 的炮弹实战 — 完整推导**

Newton 研究过抛体运动：$x(t) = v_0 \cos(\theta)·t$，$y(t) = v_0 \sin(\theta)·t - \frac{1}{2}gt^2$。

设 $v_0 = 100$ m/s，$\theta = 45°$，$g = 9.8$ m/s²。

(a) 用导数算出 t=5s 时的瞬时速度大小（先求 $v_x(t)$ 和 $v_y(t)$）
(b) 在最高点（$dy/dt = 0$），炮弹的速度是多少？方向如何？
(c) **3DGS 关联**：这个"最高点的导数为零"的现象，和你训练 Gaussian 时遇到的梯度接近零的情况有什么本质相同之处？

<details>
<summary>💡 提示</summary>
(a) $v_x = dx/dt$（常数），$v_y = dy/dt$。在 t=5s 时分别求值后合成速度大小 $\sqrt{v_x^2 + v_y^2}$。
(b) 最高点即 $v_y = 0$，此时只有水平分量。
(c) 最高点：物理上垂直方向不再上升 → 变化率为零；Gaussian 训练中：参数已经到达"足够好"的位置 → loss 对该参数的变化率趋近于零。两者都是"达到极值点时导数为零"。
</details>

<details>
<summary>✅ 参考答案</summary>
(a) $v_x = v_0\cos(45°) = 70.71$ m/s（恒定），$v_y(t) = v_0\sin(45°) - gt = 70.71 - 9.8t$。在 t=5s：$v_y = 70.71 - 49 = 21.71$ m/s。速度大小 $= \sqrt{70.71^2 + 21.71^2} ≈ 73.98$ m/s。

(b) 最高点：$v_y = 0$（即 $t = v_0\sin(45°)/g = 70.71/9.8 ≈ 7.21s$）。此时速度 = $v_x = 70.71$ m/s，方向纯水平。

(c) **本质相同**：都是函数达到极值（极大或极小）时，导数 $= 0$。炮弹最高点 → y(t) 的极大值点 → $dy/dt=0$；Gaussian 训练收敛 → L(θ_i) 对该参数的局部极小值 → $\partial L/\partial\theta_i \approx 0$。
</details>

**3.5 Leibniz vs PyTorch — 符号微分的工程实现**

Leibniz 用 $dy = f'(x)·dx$ 的规则推导导数。PyTorch autograd 做了同样的事，但自动化了：

(a) 手动推导 $f(x) = \sin(x^2)$ 的导数（从内到外：外层 sin → 中间层 x²）。
(b) 用 PyTorch 验证你的答案：

```python
import torch
x = torch.tensor(1.5, requires_grad=True)
y = torch.sin(x**2)
y.backward()
print(f"autograd: dy/dx = {x.grad.item():.6f}")

# 手算结果应该接近多少？（sin(u)'·u' = cos(u)·2x，在 x=1.5 时）
```

<details>
<summary>✅ 参考答案</summary>
(a) $y = \sin(x^2)$。令 $u = x^2$，则 $\frac{dy}{dx} = \frac{dy}{du}·\frac{du}{dx} = \cos(u) · 2x = 2x·\cos(x^2)$。
(b) 在 x=1.5：$2(1.5)·\cos(1.5^2) = 3·\cos(2.25) ≈ 3·(-0.628) ≈ -1.884$。PyTorch 输出应该接近这个值 ✅
</details>

**问题**: 用极限定义算出 $f(x)=x^2$ 在 $x=1$ 处的导数。令 $h \to 0$。

✅ **Answer**: $\frac{(1+h)^2-1}{h} = \frac{1+2h+h^2-1}{h} = 2+h$。当 $h \to 0$ 时，结果为 2。

### 2.Leibniz Symbolic
**问题**: 用 Leibniz 符号法求 $y=x^3$ 的导数：$(x+dx)^3 - x^3 \approx ?$

💡 **Hint**: 忽略高阶无穷小项 $(dx)^2, (dx)^3$。

✅ **Answer**: $dy = 3x^2 dx + 3x(dx)^2 + (dx)^3$. 忽略高阶项后 $dy \approx 3x^2 dx$, 所以 $y'=3x^2$.

### 3.Geometric Tangent

### 6.Derivative of e^x

💡 **Hint**: 指数增长率的独特性。

### 8.Chain Rule Symbolic
**问题**: 用 Leibniz 符号表示链式法则：$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$。解释中间变量 $du$ 的消去过程。

💡 **Hint**: 代数代换。

✅ **Answer**: $dy = f'(u) du, du = g'(x) dx$. 代入得 $dy = f'(u)g'(x)dx$, 两边除以 $dx$ 即得公式。这展示了符号操作的优雅之处。

### 9.Numerical Stability
**问题**: 在计算机中，为什么计算 $\frac{f(x+h)-f(x)}{h}$ 时不能取极小的 $h$（如 $10^{-20}$）？

✅ **Answer**: 当 $h$ 极小时，$(x+h)$ 和 $x$ 在浮点表示中变得非常接近，相减后会丢失大量有效数字（对阶抵消），导致结果全是噪声。

### 10.Derivative of sin(x)
**问题**: 推导 $\sin(x)$ 的导数是 $\cos(x)$。利用三角恒等式展开 $\sin(x+h)$。

💡 **Hint**: 和角公式。

✅ **Answer**: $\frac{\sin(x+h)-\sin x}{h} = \frac{\sin x \cos h + \cos x \sin h - \sin x}{h}$. 当 $h \to 0$，$\cos h \to 1, \frac{\sin h}{h} \to 1$, 结果为 $\cos x$。
