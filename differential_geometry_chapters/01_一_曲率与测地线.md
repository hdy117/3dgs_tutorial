# Ch01 — 曲率与测地线：弯曲空间的"直线"在哪里？

> **本章目标**：理解黎曼度量 (Metric Tensor) 如何定义“长度”，以及什么是“测地线”（弯曲空间里的最短路径）。  
> **前置知识**：线性代数、微积分基础。  
> **核心问题**：如果你被困在一个漆黑且扭曲的球面上，没有三维坐标，你怎么找到离你最近的地方？

---

## 🎯 问题驱动：欧几里得失效了吗？

### 场景 1：调试 3DGS 的“极端视角”

```python
# 当相机非常靠近一个平面时（比如距离 < 0.1m），渲染出的 Splat 在图像中变成了极细的线。
# 此时空间发生了剧烈的"拉伸" (Stretching)。

# 传统欧氏几何认为：直线最短，圆周长 = 2πr。
# 但在这个扭曲的投影空间中（Image Space），这些还成立吗？
```

**关键问题**：如果空间本身是弯曲的（或经过非线性映射变形了），我们如何定义"距离"和"直线"？

### 答案：**度量张量 (Metric Tensor)** —— "局部尺子的矩阵表达"

在欧几里得空间中，两点距离 $ds^2 = dx^2 + dy^2$。
但在弯曲空间（流形）中，我们需要一个**度量张量 $\mathbf{g}$** 来告诉我们在每个点的"尺子"是如何刻度的。

---

## 📐 Part 1: 度量张量 (Metric Tensor) — 空间的"标尺"

### Boxed Result：广义距离公式 (Riemannian Metric)

对于参数化坐标 $(u, v)$，其对应的物理长度平方 $ds^2$ 为：
$$oxed{ds^2 = \mathbf{dx}^T \mathbf{G} \mathbf{dx} = g_{11} du^2 + 2g_{12} du dv + g_{22} dv^2}$$

其中 $\mathbf{G}$ 是 **度量张量矩阵** (Metric Matrix)，是一个对称正定矩阵。
- $g_{ij}$：坐标轴之间的"夹角与刻度"。如果 $g_{12}=0$，说明坐标轴正交；如果不为 0，说明坐标轴倾斜了（剪切变形）。

### 💡 几何直觉：从雅可比 (Jacobian) 到度量张量

假设我们有一个 3D 表面被映射到参数空间 $(u, v)$。
**Boxed Result：度量张量的本质是雅可比矩阵的内积**
$$oxed{\mathbf{G} = \mathbf{J}^T \mathbf{J}}$$
其中 $\mathbf{J}$ 是将参数变化映射到物理空间（3D世界）的雅可比矩阵。

这意味着：**度量张量记录了空间在每一个点的"拉伸与旋转"程度**。它是欧几里得几何在弯曲空间中的推广！

---

## 🔥 Part 2: 测地线 (Geodesic) — "弯曲空间里的直线"

### Boxed Result：测地线的定义

测地线是流形上两点之间的**局部最短路径**。
在物理直觉上，它满足：**沿着这条路线走，你的加速度为 0**（没有转弯，也没有加速减速）。

数学表达（Geodesic Equation）：
$$oxed{rac{d^2 x^\mu}{dt^2} + \Gamma^\mu_{
uho} rac{dx^
u}{dt} rac{dx^ho}{dt} = 0}$$

其中 $\Gamma$ (Christoffel Symbols) 是"仿射联络"，它描述了坐标系的弯曲程度。
**直觉解读**：$rac{d^2 x}{dt^2}$ 是你感受到的物理加速度；$\Gamma$ 则是坐标系弯曲产生的"科里奥利力"（惯性项）。测地线就是抵消了坐标系假想力的真实直线！

## 💻 Part 3: PyTorch 验证 — 从雅可比计算度量张量

```python
import torch

# ============================================================
# 1. 构造一个简单的 3D 曲面：圆柱面 (x=cos(u), y=sin(u), z=v)
# ============================================================
print("=== 圆柱面的度量张量 ===")

u = torch.tensor([0.5], dtype=torch.float32, requires_grad=True) # 角度
v = torch.tensor([1.0], dtype=torch.float32, requires_grad=True) # 高度

def surface(u, v):
    return torch.stack([torch.cos(u), torch.sin(u), v])

# 计算雅可比矩阵 J (3x2)，描述参数变化如何影响物理坐标
params = [u, v]
J_cols = []
for p in params:
    # d(surface)/dp
    g = torch.autograd.grad(surface(u, v).sum(), p, create_graph=True)[0]
    J_cols.append(g)

J = torch.stack(J_cols, dim=1) # Shape: (3, 2) -> [du_vec, dv_vec]

# 计算度量张量 G = J^T * J
G = J.T @ J 
print(f"参数坐标：u={u.item():.2f}, v={v.item():.2f}")
print(f"雅可比矩阵:
{J.detach()}") # u方向切向量, v方向切向量
print(f"度量张量 G:
{G.detach().numpy()}")

# 💡 对于圆柱面，du 方向的物理长度是半径 r=1 (所以 g_11 = 1^2 = 1)。
# dv 方向长度也是 1 (g_22 = 1)。它们正交 (g_12 = 0)。

# ============================================================
# 2. 弯曲空间中的"直线"：测地线数值模拟
# ============================================================
print("
=== 测地线 (Geodesic) 模拟 ===")

# 假设我们在圆柱面上，从点 A(0,0) 走到点 B(π/2, 1)。
# 在平展的纸上（展开图），这是直线。但在柱面上，这是一条螺旋线！
import matplotlib.pyplot as plt

t = torch.linspace(0, 1, 50)
path_u = t * (torch.pi / 2) # u 从 0 到 pi/2
path_v = t * 1.0           # v 从 0 到 1

x_path = torch.cos(path_u)
y_path = torch.sin(path_u)
z_path = path_v

# 计算路径长度 (数值积分)
dx = torch.diff(x_path)
dy = torch.diff(y_path)
dz = torch.diff(z_path)
ds = torch.sqrt(dx**2 + dy**2 + dz**2)
total_length = ds.sum().item()

print(f"测地线（螺旋线）长度: {total_length:.4f}")
# 理论展开距离：sqrt((pi/2)^2 + 1^2) ≈ sqrt(2.467 + 1) ≈ 1.86
```

## 🗺️ Part 5: 与 3DGS 的衔接点 — "扭曲的空间"在哪里？

虽然 3DGS 的物理空间是欧几里得的（直的），但**图像空间 (Image Space)** 是被投影扭曲的。

| 概念 | 3DGS 中的体现 |
|------|--------------|
| **度量张量 $\mathbf{G}$** | 在图像平面上的每一个像素，都有一个从 3D 场景映射过来的局部度量。它描述了 Splat 在该像素处的"拉伸程度"（由投影雅可比决定）。 |
| **测地线 (Geodesic)** | 如果你在训练中加入 "空间正则化"（例如约束相邻 Splat 的位置关系），你实际上是在流形上定义了一种"最短路径"约束。 |
| **曲率** | 当相机视角极偏时，Splat 的投影会极度扭曲（高斯曲率效应）。理解度量张量 $\mathbf{G} = \mathbf{J}^T\mathbf{J}$ 是处理这种"病态变形"的关键。 |

### 💡 关键洞察：3DGS 是一个动态黎曼空间
每个 Splat 都是一个椭球（局部曲率为常数）。当它投影到 2D 时，度量张量 $\mathbf{G}$ 会发生剧烈的变化。优化过程本质上是在**寻找一组参数配置，使得在扭曲的图像度量下，重建误差最小**。

## 🎓 本章小结

### 核心公式 (Boxed)

$$oxed{	ext{度量张量: } \mathbf{G} = \mathbf{J}^T \mathbf{J}, \quad ds^2 = \mathbf{dx}^T \mathbf{G} \mathbf{dx}}$$

$$oxed{	ext{测地线方程: } rac{d^2x^\mu}{dt^2} + \Gamma^\mu_{
uho}\dot{x}^
u\dot{x}^ho = 0}$$

### 关键洞察

> **度量张量是空间的"标尺"** —— 它告诉我们坐标轴之间的真实物理距离和夹角。在 3DGS 中，雅可比矩阵 $\mathbf{J}$ 就是连接欧氏空间与图像扭曲空间的桥梁。
> 
> **测地线是"加速度为零的路径"** —— 在弯曲空间中，它就是我们要找的"直线"。理解它有助于我们在训练中加入基于几何先验的正则化（例如保持局部结构的平坦性）。

## 📚 习题

### ✅ 基础题

**1.1** 证明：对于欧几里得空间中的旋转坐标系，度量张量 $\mathbf{G}$ 依然是单位矩阵。
<details>
<summary>💡 提示</summary> 雅可比矩阵 $\mathbf{J}$ 是正交矩阵（旋转）。$\mathbf{G} = \mathbf{J}^T\mathbf{I}\mathbf{J} = \mathbf{J}^{-1}\mathbf{J} = \mathbf{I}$。
</details>

**1.2** 度量张量 $\mathbf{G}$ 的非对角项 $g_{12}$ 不为零时，说明坐标系发生了什么变化？
<details>
<summary>💡 提示</summary> 说明两个坐标轴不再正交（夹角不是 90°），或者发生了剪切变形 (Shearing)。
</details>

### 🔥 进阶题

**1.3** (黎曼几何)：为什么在弯曲空间中，平行移动一个向量到终点后，它的方向通常会改变？这在物理上怎么理解？
<details>
<summary>💡 提示</summary> 因为存在非零的 Christoffel Symbols $\Gamma$（曲率）。物理上可以理解为"科里奥利力"——如果你在一个旋转参考系中保持"直线"走，相对于地面观察者，你的方向似乎在弯曲。
</details>

### 💡 3DGS 关联题

**1.4** (投影畸变)：在 3DGS 的渲染管线中，当我们计算 Splat 对像素的贡献时，我们隐含地使用了图像空间的度量张量 $\mathbf{G}_{img}$。如果 $\det(\mathbf{G}_{img})$ 非常大（极度拉伸），这对渲染稳定性有什么影响？
<details>
<summary>💡 提示</summary> $\det(\mathbf{G}) = \det(\mathbf{J}^T\mathbf{J}) = (\det \mathbf{J})^2$。这代表了雅可比行列式的平方，即"体积放大倍率"。如果极度拉伸（极大），意味着微小的 3D 偏差会导致极大的像素变化，梯度会爆炸（数值不稳定）。这正是极端视角下 3DGS 崩溃的原因。
</details>
