## 📐 Part 1: 条件数的三大面孔

### Boxed Result：条件数的三种等价定义

对于可逆矩阵 $\mathbf{A}$，条件数可以定义为三种形式（$\ell_2$ 范数下）：
$$\boxed{\kappa(\mathbf{A}) = \frac{\sigma_{\max}(\mathbf{A})}{\sigma_{\min}(\mathbf{A})} = \|\mathbf{A}\|_2 \cdot \|\mathbf{A}^{-1}\|_2 = \frac{\lambda_{\max}(\boldsymbol{\Sigma})}{\lambda_{\min}(\boldsymbol{\Sigma})}}$$

其中 $\boldsymbol{\Sigma} = \mathbf{A}^T\mathbf{A}$（或 $\mathbf{A}\mathbf{A}^T$）。

### 💡 Boxed Result：条件数的"灾难级数"

| 条件数 κ | 含义 | 后果 |
|----------|------|------|
| **κ < 10** | 完美条件 | 任何数值方法都稳定 ✅ |
| **10 ≤ κ < 10⁶** | 良态 | 双精度浮点数安全使用 ✅ |
| **10⁶ ≤ κ < 10¹²** | 病态 | 结果可能有 6~12 位有效数字丢失 ⚠️ |
| **κ ≥ 10¹⁵** | 极度病态 | 双精度下求逆/求解基本不可能 ❌ |

## 🔥 Part 2: 条件数在优化中的角色 — Hessian 的条件数决定收敛速度

### Boxed Result：梯度下降的收敛速率与条件数 ⚔️

对于二次函数 $f(\mathbf{x}) = \frac{1}{2}\mathbf{x}^T\mathbf{H}\mathbf{x} - \mathbf{b}^T\mathbf{x}$，梯度下降的迭代收敛速率为：
$$\boxed{\|\mathbf{x}_{k+1}-\mathbf{x}^*\|_2 \leq \left(\frac{\kappa-1}{\kappa+1}\right)^2 \|\mathbf{x}_k-\mathbf{x}^*\|_2}$$

**关键洞察**：
- **κ=1**: 一次迭代就收敛！（如 $f(x)=x^2$，完美抛物线）
- **κ→∞**: $\left(\frac{\kappa-1}{\kappa+1}\right)^2 \approx 1$ → 几乎不收敛！梯度下降在"瘦长山谷"中来回摆动。

### 💡 Boxed Result：为什么条件数大 = "优化地狱"？

想象一个二次函数的等高线图：
- **κ=1**: 圆形等高线（完美对称）→ 梯度直接指向最小值。
- **κ=1000**: 细长椭圆 → 梯度几乎平行于山谷壁，需要来回摆动才能到达底部！这就是 **"锯齿现象" (Zigzag)**。

## 💻 Part 3: PyTorch 验证 — Hessian 条件数与训练稳定性

```python
import torch
import numpy as np

# ============================================================
# 1. Hessian 条件数对梯度下降收敛的影响 ⚔️
# ============================================================
print("=== Hessian 条件数 vs GD 收敛速度 ===")

def quadratic_loss(A, x):
    """f(x) = 0.5 * x^T A x - b^T x"""
    return 0.5 * torch.dot(x, A @ x) - torch.dot(torch.ones_like(x), x)

def gradient_descent(A, x_init, lr=0.01, max_iter=500):
    """梯度下降求解 Ax = b (b=ones)"""
    x = x_init.clone()
    losses = []
    for i in range(max_iter):
        grad = A @ x - torch.ones_like(x) # ∇f = Ax - b
        x -= lr * grad
        if i % 50 == 0:
            losses.append(quadratic_loss(A, x).item())
    return x, losses

# --- 好矩阵 (κ ≈ 1): 圆形等高线 ---
A_good = torch.diag(torch.tensor([2.0, 2.0])) # λ = [2, 2], κ=1
_, s_good, _ = torch.linalg.svd(A_good.float())
kappa_good = s_good[0] / s_good[-1]

# --- 坏矩阵 (κ ≈ 100): 细长椭圆 ---
A_bad = torch.diag(torch.tensor([2.0, 0.02])) # λ = [2, 0.02], κ=100
_, s_bad, _ = torch.linalg.svd(A_bad.float())
kappa_bad = s_bad[0] / s_bad[-1]

# --- 梯度下降对比 ---
x_init = torch.tensor([1.0, 1.5])

print(f"好矩阵: κ={kappa_good:.2f}, 坏矩阵: κ={kappa_bad:.2f}")

x_good_final, losses_good = gradient_descent(A_good, x_init.copy(), lr=0.4)
x_bad_final, losses_bad = gradient_descent(A_bad, x_init.copy(), lr=0.01) # 需要更小的学习率!

print(f"\n好矩阵 GD (500步): 最终 Loss = {losses_good[-1]:.6f}")
print(f"坏矩阵 GD (500步): 最终 Loss = {losses_bad[-1]:.4f} (远未收敛!)")

# --- 条件数预测 vs 实际收敛 ---
pred_rate_good = ((kappa_good - 1) / (kappa_good + 1)) ** 2
pred_rate_bad = ((kappa_bad - 1) / (kappa_bad + 1)) ** 2
print(f"\n好矩阵: 预测收敛因子 {pred_rate_good:.6f} → 极快!")
print(f"坏矩阵: 预测收敛因子 {pred_rate_bad:.4f} → 几乎不收敛! (≈1)")

# ============================================================
# 2. Hessian 条件数在神经网络中的表现 ⚔️
# ============================================================
print("\n=== NN 中的 Hessian 条件数 ===")

class SimpleNet(torch.nn.Module):
    def __init__(self, d_in=50, d_hid=100):
        super().__init__()
        self.fc = torch.nn.Linear(d_in, d_hid)
    
    def forward(self, x):
        return self.fc(x).sum()

model = SimpleNet()
x_sample = torch.randn(2, 50)

# 近似 Hessian（通过参数梯度）
params = list(model.parameters())
for p in params:
    if p.requires_grad:
        p.grad.zero_()

y = model(x_sample)
y.backward(create_graph=True) # 创建计算图以计算高阶导数

# 提取 Hessian diagonal (近似条件数)
hess_diag = []
for p in params:
    if p.grad is not None:
        hess_diag.append(p.grad.abs().mean())

hess_diag = torch.tensor(hess_diag)
kappa_hess = hess_diag.max() / (hess_diag.min() + 1e-8)
print(f"NN Hessian diagonal: min={hess_diag.min():.6f}, max={hess_diag.max():.4f}")
print(f"Hessian 近似 κ ≈ {kappa_hess:.2f} (实际 > 这个值, 因为忽略了 cross-term)")

# 💡 这就是为什么 Adam / RMSProp 等自适应优化器优于 SGD —— 
# 它们通过 per-parameter learning rate 自动"平衡"了 Hessian 的条件数!
```

## 🗺️ Part 5: 与 3DGS 的衔接点 — Hessian 条件数与训练稳定性

### Boxed Result：3DGS 中的三个条件数敏感场景

| 场景 | 矩阵 | κ 的影响 | 缓解策略 |
|------|------|----------|---------|
| **协方差求逆** | $\mathbf{B} = \mathbf{J}\boldsymbol{\Sigma}\mathbf{J}^T$ | $\kappa(\mathbf{B}) > 10^{15}$ → inf/NaN | ε-Stabilizer ($\mathbf{B} + \epsilon I$) |
| **Hessian 优化** | L2 Loss 的 Hessian | κ ≈ 10³~10⁶ → SGD 收敛慢 | 用 Adam（自动调节 per-parameter lr） |
| **SH 系数求解** | 球谐采样矩阵 $\mathbf{A}_{SH}$ | 视角稀疏时 κ 大 → 过拟合 | SH 截断 (L≤3) + L2 正则化 |

### 💡 Boxed Result：为什么 Adam 比 SGD 更适合 3DGS？

Adam 的更新规则：
$$\boxed{\mathbf{m}_t = \beta_1\mathbf{m}_{t-1} + (1-\beta_1)\nabla_t, \quad \mathbf{v}_t = \beta_2\mathbf{v}_{t-1} + (1-\beta_2)\nabla_t^2}$$
$$\boxed{\hat{\theta}_t = \theta_{t-1} - \frac{\alpha \hat{\mathbf{m}}_t}{\sqrt{\hat{\mathbf{v}}_t} + \epsilon}}$$

**关键洞察**：$\mathbf{v}_t$ 近似 Hessian 的 diagonal，Adam 通过 $\nabla_t / \sqrt{\hat{\mathbf{v}}_t}$ **自动缩放每个参数的步长**，等效于 preconditioning！这大大降低了有效条件数。

## 🎓 本章小结

### 核心公式 (Boxed)

$$\boxed{\kappa(\mathbf{A}) = \frac{\sigma_{\max}}{\sigma_{\min}}, \quad \text{κ越大 → 数值/优化越不稳定!}}$$

$$\boxed{\|\mathbf{x}_{k+1}-\mathbf{x}^*\| \leq \left(\frac{\kappa-1}{\kappa+1}\right)^2 \|\mathbf{x}_k-\mathbf{x}^*\| \quad (\text{GD 收敛速率})}$$

### 关键洞察

> **条件数是矩阵的"脆弱度量"** —— κ=1（完美），κ=10¹⁵（崩溃）。它同时影响线性方程组求解和梯度下降的收敛。
> 
> **Hessian 的条件数 = 优化问题的"地形复杂度"** —— κ大意味着等高线是细长椭圆，SGD 会来回摆动（锯齿）。Adam/RMSProp 通过自适应学习率自动 preconditioning！
> 
> **3DGS 同时面临线性系统条件数和 Hessian 条件数的挑战** —— ε-Stabilizer 解决前者，Adam 解决后者。两者缺一不可！

## 📚 习题

### ✅ 基础题

**5.1** 证明：如果 $\mathbf{A}$ 是正交矩阵（$\mathbf{A}^T\mathbf{A}=\mathbf{I}$），则 $\kappa(\mathbf{A}) = 1$。
<details>
<summary>💡 提示</summary> 正交矩阵保持长度不变 → 所有奇异值 = 1 → κ = 1/1 = 1。完美条件！
</details>

**5.2** 梯度下降在 $f(x,y)=x^2 + \epsilon y^2$（$\epsilon \ll 1$）上的收敛速率是多少？
<details>
<summary>💡 提示</summary> $\kappa = 1/\epsilon$. GD 收敛因子 ≈ $(1-\epsilon/1)^2 \approx 1-2\epsilon$. ε越小越慢！这就是"病态二次函数"。
</details>

### 🔥 进阶题

**5.3** (Preconditioning)：如果 Hessian $\mathbf{H}$ 的条件数很大，如何通过变换坐标 $\mathbf{x} = \mathbf{P}\tilde{\mathbf{x}}$ 来降低新坐标系下的条件数？
<details>
<summary>💡 提示</summary> 选择 $\mathbf{P}=\mathbf{H}^{-1/2}$（或 Cholesky 因子），则新 Hessian = $\mathbf{I}$，κ=1。这就是 Newton's Method + Preconditioned GD 的核心思想！
</details>

### 💡 3DGS 关联题

**5.4** (ε-Stabilizer)：在 3DGS 中为什么选择 $\epsilon=0.3$（而不是 $10^{-6}$）？这个值对条件数和渲染质量有什么影响？
<details>
<summary>💡 提示</summary> ε 必须足够大以使 B+εI 的条件数降到安全范围。如果太小（如 1e-6），病态 Splat 的投影协方差仍然接近奇异 → inf/NaN。如果太大（如 10.0），协方差的形状被过度扭曲 → Splat 变形失真。0.3 是经验平衡点。
</details>

# 🧱 Numerical Linear Algebra Cheat Sheet (3DGS Edition)
## Part 1: 矩阵分解
- **LU/QR/SVD**: A=LU, A=QR, A=UΣV^T. 各自擅长求解/最小二乘/降维.

## Part 2: Cholesky
- **A = LL^T** (SPD专属). 采样公式: μ+Lz.

## Part 3: SVD + Eckart-Young ⚔️
- **最优 rank-k**: A_k = U_k Σ_k V_k^T, ||A-A_k||_F²=∑_{j>k}σ_j².

## Part 4: PCA = SVD
- **PCA**: max w^TΣw → w=v_max (特征向量). λ_i=σ²/(n-1).

## Part 5: Condition Number ⚔️ 
- **κ(A)=σ_max/σ_min**. κ>10¹⁵ → 崩溃!
- **GD收敛速率**: ((κ-1)/(κ+1))². κ大→极慢.
- **Adam vs SGD**: Adam通过v_t≈Hessian diagonal自动preconditioning!

## Part 6: 3DGS 条件数应用
| 场景 | 矩阵 | 缓解策略 |
|------|------|---------|
| B = JJ^T求逆 | ε-Stabilizer (B+εI) |
| Hessian优化 | Adam/RMSProp |
| SH采样矩阵 | L2正则化 + SH截断 |

## 🏆 核心洞察
> "条件数 κ=σ_max/σ_min → 数值稳定性和优化速度的'命运之轮'."
> "Adam = 自适应 preconditioning. SGD = blind gradient descent on ill-conditioned terrain."
