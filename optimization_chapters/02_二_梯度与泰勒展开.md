## 📐 Part 1: 泰勒展开 (Taylor Series) — "局部线性化"的魔法

### 直觉：用一条直线/平面去拟合复杂的曲面

在微积分中，我们知道**导数就是切线斜率**。泰勒展开把这一思想推广到了更高维度——它告诉我们：**在极小的邻域内，任何复杂的函数都可以近似为一个线性模型（多变量下的"切平面"）。**

### Boxed Result：一维泰勒展开 (保留到二阶项)

$$\boxed{f(x + \Delta x) \approx f(x) + f'(x)\Delta x + \frac{1}{2}f''(x)(\Delta x)^2}$$

- **零阶项** $f(x)$：当前的高度。
- **一阶项** $f'(x)\Delta x$：线性变化量（斜率 $\times$ 步长）。
- **二阶项** $\frac{1}{2}f''(x)(\Delta x)^2$：曲率带来的修正（碗状/山状的弯曲程度）。

### Boxed Result：多元泰勒展开 (向量版) — 优化的灵魂！

设 $\mathbf{x}$ 是参数向量，$\nabla f(\mathbf{x})$ 是梯度，$\nabla^2 f(\mathbf{x})$ 是海森矩阵（Hessian）。
$$\boxed{f(\mathbf{x} + \Delta \mathbf{x}) \approx f(\mathbf{x}) + \nabla f(\mathbf{x})^T \Delta \mathbf{x} + \frac{1}{2} \Delta \mathbf{x}^T \nabla^2 f(\mathbf{x}) \Delta \mathbf{x}}$$

**拆解这个公式**：
1. $f(\mathbf{x})$：当前位置的 Loss 值。
2. $\nabla f(\mathbf{x})^T \Delta \mathbf{x}$：**一阶近似**。Loss 随参数变化的线性部分（方向）。
3. $\frac{1}{2} \Delta \mathbf{x}^T \mathbf{H} \Delta \mathbf{x}$：**二阶近似**。曲率项。如果曲率很大，说明函数很陡峭或弯曲剧烈。

---

## 🔥 Part 2: 梯度 (Gradient) — "最速下降方向"的严格证明

### 核心结论 (Boxed Result)

$$\boxed{\text{沿着 } -\nabla f(\mathbf{x}) \text{ 走，Loss 下降最快！}}$$

### 🔥 第一性原理推导：为什么是梯度？

假设我们要寻找一个方向 $\mathbf{d}$（$\|\mathbf{d}\|=1$），使得在步长 $\eta$ (极小值) 下的函数变化量最小。
利用泰勒展开的一阶近似（忽略高阶项，因为 $\Delta \mathbf{x} = \eta \mathbf{d}$ 极小）：
$$\Delta f \approx \nabla f(\mathbf{x})^T (\eta \mathbf{d}) = \eta \cdot \nabla f(\mathbf{x})^T \mathbf{d}$$

我们要最小化 $\Delta f$。根据**柯西-施瓦茨不等式 (Cauchy-Schwarz Inequality)**：
$$\nabla f^T \mathbf{d} = \|\nabla f\| \|\mathbf{d}\| \cos\theta \geq -\|\nabla f\|$$

其中 $\theta$ 是梯度方向与移动方向的夹角。
要使变化量最小（即最负），必须让 $\cos\theta = -1$，也就是 **$\theta = 180^\circ$**！

这意味着：**你移动的方向必须与梯度的方向完全相反！** ∎

### 💡 几何直觉：等高线 (Contour Lines)
想象一张地形图。梯度矢量垂直于等高线，指向高海拔处。所以梯度的反方向就是垂直指向低海拔处的"下坡箭头"。

---

## 📐 Part 3: 步长 (Learning Rate) — 牛顿的警告："不要跑太快！"

### Boxed Result：梯度下降更新公式 (Gradient Descent, GD)

$$\boxed{\mathbf{x}_{k+1} = \mathbf{x}_k - \eta \cdot \nabla f(\mathbf{x}_k)}$$

其中 $\eta$ 是**学习率 (Learning Rate)**。

### 💡 步长过大的灾难：越过山谷 (Overshooting)

如果只看一阶泰勒展开 ($\Delta x^2$ 项被忽略了)，我们会以为函数是一条无限延伸的直线。但实际函数可能有曲率（二阶项）。
- **情况 A (小步长)**：$\eta \nabla f$ 很小，我们稳稳地走向最低点。
- **情况 B (大步长)**：我们在当前位置往右走了一步，结果直接飞过了谷底，落在了右边的半山腰，甚至比起点还高！

**数学解释（利用二阶泰勒展开）**：
$$f(\mathbf{x} - \eta \nabla f) \approx f(\mathbf{x}) - \eta \|\nabla f\|^2 + \frac{\eta^2}{2} \nabla f^T \mathbf{H} \nabla f$$
要使 Loss 真的下降，第一项（负的一阶项）必须压倒第二项（正的二阶曲率项）。这要求 $\eta < \frac{\|\nabla f\|^2}{\nabla f^T \mathbf{H} \nabla f}$。

## 💻 Part 4: PyTorch 验证 — 梯度下降的可视化模拟

```python
import torch
import numpy as np
import matplotlib.pyplot as plt

# ============================================================
# 1. 构造一个非凸的测试函数 (山地地形)
# f(x, y) = x^2 + 0.1y^4 - 0.5x*y  (碗状但有扭曲)
# ============================================================
print("=== 梯度下降路径可视化 ===")

def f(x, y): return x**2 + 0.1 * y**4 - 0.5 * x * y

# 解析梯度 (Gradient)
def grad_f(x, y):
    df_dx = 2*x - 0.5*y
    df_dy = 0.4 * y**3 - 0.5*x
    return df_dx, df_dy

# ============================================================
# 2. 模拟 GD 过程 (手动实现)
# ============================================================
x_hist, y_hist = [], []
lr = 0.1 # 学习率

# 随机起点
curr_x, curr_y = 3.0, -4.0 
path = [(curr_x, curr_y)]

for step in range(50):
    dx, dy = grad_f(curr_x, curr_y)
    
    # GD Update: x_new = x_old - lr * grad
    curr_x -= lr * dx
    curr_y -= lr * dy
    
    path.append((curr_x, curr_y))
    if abs(dx) < 1e-4 and abs(dy) < 1e-4: 
        break # 收敛停止

print(f"起始点: {path[0]} -> Loss: {f(*path[0]):.2f}")
final = path[-1]
print(f"终止点: {final} -> Loss: {f(*final):.6f}")

# ============================================================
# 3. PyTorch Autograd 验证 (自动求导 vs 解析解)
# ============================================================
from torch.autograd import gradcheck

x_test = torch.tensor([0.5, 0.8], dtype=torch.double, requires_grad=True)
def test_fn(x): return x[0]**2 + 0.1 * x[1]**4 - 0.5 * x[0] * x[1]

# 检查 PyTorch 算的梯度对不对 (数值微分法)
is_correct = gradcheck(test_fn, (x_test,), eps=1e-6, atol=1e-4)
print(f"\nPyTorch Autograd 精度验证: {is_correct} ✅")

# ============================================================
# 4. 步长过大导致的 "震荡" 演示
# ============================================================
print("\n=== 步长过大 (Larger LR) ===")
large_lr = 0.8 # 很大！
x, y = 3.0, -4.0
for i in range(5):
    dx, dy = grad_f(x, y)
    x -= large_lr * dx; y -= large_lr * dy
    print(f"Step {i}: (x,y)=({x:.2f}, {y:.2f}), Loss={f(x,y):.4f}")

# 💡 如果 lr=0.8，Loss 可能会在第 1、2 步不降反升！这就是梯度爆炸/震荡。
```

## 🗺️ Part 5: 与 3DGS 的衔接点 — 为什么我们需要 Adam？

### 核心问题：3DGS 的 Loss 曲面极其"病态 (Ill-conditioned)"

在优化理论中，如果一个函数的**海森矩阵 $\mathbf{H}$ 的特征值差异巨大**（有的方向很平，有的方向极陡），我们就说它是"病态"的。

| 现象 | 3DGS 中的表现 | 为什么 GD (Ch02) 会失效？ |
|------|--------------|--------------------------|
| **狭窄的峡谷 (Ravines)** | Splat 的位置 $\mu$ 对 Loss 影响极大（极陡），而颜色 $c$ 影响较小（平缓）。 | 如果你用统一的步长 $\eta$，在 $\mu$ 方向上会震荡爆炸，在 $c$ 方向上又几乎不动。 |
| **鞍点 (Saddle Points)** | 某些参数配置下，Loss 在某方向是极小值，在另一方向是极大值（曲率为负）。 | 梯度为 0 ($\nabla f = 0$)，GD 会以为到了最低点并停止。 |
| **非凸性 (Non-convex)** | 参数空间里有无数个局部极小值。 | GD 只能保证收敛到最近的局部低点，不保证全局最优。 |

### 💡 解决方案：自适应学习率 (Adam) — "给每个维度不同的步长"

这就是下一章的主题：**SGD with Momentum & Adam**。
简单来说：
- **Momentum**: "加上惯性" —— 解决震荡问题（利用历史梯度的动量冲过鞍点）。
- **RMSProp/Adam**: "自适应调整" —— 在陡峭方向自动缩小步长，在平缓方向放大步长。这本质上是在**近似逆海森矩阵 (Inverse Hessian)**！

## 🎓 本章小结

### 核心公式

$$\boxed{f(\mathbf{x} + \Delta \mathbf{x}) \approx f(\mathbf{x}) + \nabla f^T \Delta \mathbf{x} + \frac{1}{2} \Delta \mathbf{x}^T \mathbf{H} \Delta \mathbf{x}}$$

$$\boxed{\text{GD Update: } \mathbf{x}_{k+1} = \mathbf{x}_k - \eta \nabla f(\mathbf{x}_k) \quad (\text{沿梯度反方向})}$$

### 关键洞察

> **泰勒展开是优化器的"显微镜"** —— 它让我们在不可知的黑盒函数中，也能看清局部的地形。
> 
> **梯度方向 = 最速下降方向**（数学上由柯西-施瓦茨不等式保证）。这是所有深度学习训练器的物理基础。
> 
> **步长 $\eta$ 是双刃剑**：太小收敛慢；太大越过谷底 (Overshooting)。3DGS 中通常需要动态调整学习率（Warmup + Decay）。

### ✅ 基础题

**2.1** 对于函数 $f(x) = x^4 - 2x^2$，写出它在任意点 $x$ 处的一阶泰勒展开式。
<details>
<summary>💡 提示</summary>
$f'(x) = 4x^3 - 4x$. 
一阶展开: $f(x+\Delta x) \approx (x^4-2x^2) + (4x^3-4x)\Delta x$.
</details>

**2.2** 证明：在极小值点，梯度 $\nabla f(\mathbf{x})$ 必须等于零向量。
<details>
<summary>💡 提示</summary>
如果在极小值点梯度不为0（比如指向右下方），那么根据 GD 规则，往反方向走一步 Loss 就会下降。这与"它是最低点"矛盾！因此驻点的必要条件就是 $\nabla f = 0$。
</details>

### 🔥 进阶题

**2.3** (泰勒展开二阶项的应用)：假设你在一维函数 $f(x)$ 的极小值附近，已知 $f'(x_0)=0, f''(x_0)=h > 0$。如果步长是 $\Delta x$，求 Loss 的真实下降量（精确到二阶）。
<details>
<summary>💡 提示</summary>
$f(x+\Delta x) - f(x) \approx 0 + \frac{1}{2}h(\Delta x)^2$. 
注意：因为 $\nabla f=0$，一阶项消失了！下降量完全由曲率 $h$ 和步长平方决定。这也是为什么在接近最优解时，收敛速度会变慢（二次收敛）。
</details>

### 💡 3DGS 关联题

**2.4** 在 3DGS 中，Splat 的协方差矩阵 $\Sigma$ 如果初始设定得太尖锐（曲率极大），为什么会导致梯度下降"震荡"？请用泰勒展开的二阶项解释。
<details>
<summary>💡 提示</summary>
$\Sigma$ 越尖，意味着 Splat 的变化对 Loss 的影响呈指数级放大（极陡的曲率 $f''(x)$ 很大）。根据二阶泰勒展开 $\frac{1}{2}h(\Delta x)^2$，如果 $h$ 巨大，任何微小的步长 $\Delta x$ 都会导致巨大的 Loss 变化。如果不减小学习率 $\eta$，模型就会在谷底两侧疯狂跳跃（震荡发散）。
</details>
