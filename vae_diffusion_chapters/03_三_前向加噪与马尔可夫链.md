> **本章目标**：从第一性原理推导扩散模型的前向过程，理解为什么逐步加噪比一次性加噪更优雅。  
> **前置知识**：Ch01-02 (VAE + ELBO)、概率论 Ch07 (高斯性质)、优化理论 Ch04 (凸优化)。  
> **核心问题**：如果目标是把数据变成纯噪声，为什么要一步一步来？马尔可夫假设带来了什么红利？

## 🎯 问题驱动：暴力加噪 vs 优雅扩散

### 场景 1：从图像到噪声的"死亡螺旋"

```python
import torch
from torch import nn

# 想象你想训练一个模型，让它能从纯噪声中生成数据。
# 最暴力的做法是什么？

x_0 = torch.randn(64, 3, 256, 256)     # batch=64, 原始图像

# 暴力方案：一次性加极大噪声
sigma_max = 10.0
x_T = x_0 + sigma_max * torch.randn_like(x_0)   # ←←← 几乎全是噪声了！

# 问题：训练时用什么作为条件？x_T ≈ N(0, σ²)，和任何数据的分布都差不多
# 解码器需要学会"从随机噪声中恢复特定数据"——这是一个不可能的任务。

# 优雅方案：逐步加噪（扩散）
T = 1000                       # 时间步数
betas = torch.linspace(0, 0.02, T)     # 方差调度
x_t = x_0
for t in range(T):
    epsilon = torch.randn_like(x_t)
    x_t = (1 - betas[t]) * x_t + betas[t] * epsilon  # ←←← 逐步扰动
```

**关键问题 🔥**：

| 方案 | 优点 | 致命缺陷 |
|------|------|----------|
| **一次性加噪** | 简单，一步到位 | $x_T$ 丢失所有结构信息；解码器无从下手 |
| **逐步加噪（扩散）** | 每步只加微小噪声 → 中间状态有结构 | 需要训练 T 个不同时刻的模型？计算量爆炸 |

## 📐 Part A: 马尔可夫链——扩散的第一性原理假设

### Dimension 1: Axioms（不可约的事实）

1. **马尔可夫性质**：未来只依赖当前状态，不依赖过去历史
   $$p(x_t|x_0, x_{t-1}, \ldots, x_1) = p(x_t|x_{t-1})$$
2. **高斯转移的闭式性**：两个高斯卷积仍是高斯
3. **链式法则**：联合分布可以分解为条件分布的乘积

### Dimension 2: Forced Problems（被迫发明什么矛盾？）

如果我们想从 $x_0$ 逐步加噪到 $x_T \approx \mathcal{N}(0, I)$，我们需要定义每一步的转移概率 $q(x_t|x_{t-1})$。

**选择 1：直接指定任意转移**
$$q(x_t|x_{t-1}) = \text{某种分布}$$
问题：联合分布 $q(x_1, \ldots, x_T|x_0) = \prod_{t=1}^T q(x_t|x_{t-1})$ ——但我们需要计算任意时刻 $x_t$ 的闭式表达式，这需要做 T-1 次卷积。

**选择 2：马尔可夫假设 + 高斯转移**
$$q(x_t|x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t}x_{t-1}, \beta_t I)$$
红利：通过重参数化技巧（Ch02），我们可以直接计算 $q(x_t|x_0)$ 的闭式解，无需做 T 次卷积！

> **矛盾解决**：马尔可夫假设让"逐步加噪"在计算上可行——我们不需要模拟每一步，而是可以用一个公式跳到任意时刻 $t$。

### Dimension 3: Solution Path（唯一合理的解决路径）

定义前向过程为马尔可夫链：
$$q(x_1, \ldots, x_T|x_0) = \prod_{t=1}^T q(x_t|x_{t-1})$$

其中每步是**高斯扰动**：
$$\boxed{q(x_t|x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t}\, x_{t-1}, \beta_t I)}$$

这里 $\beta_t \in (0, 1)$ 是**方差调度参数**（variance schedule），通常设为线性或余弦递减。

**为什么用 $\sqrt{1-\beta_t}$ 而不是 $1-\beta_t$？**
因为我们要保持"能量守恒"——如果每步收缩系数是 $\alpha_t = 1 - \beta_t$，那么经过 T 步后：
$$x_T = x_0 \cdot \prod_{t=1}^T \sqrt{\alpha_t} + \text{噪声累加}$$

我们需要 $\prod_{t=1}^T \alpha_t \to 0$（完全破坏信号），同时保留中间时刻的可恢复性。用平方根形式是为了后面推导简洁——详见 Step 3。

## 🔥 Part B: 闭式解 $q(x_t|x_0)$ 的一阶原理推导

现在从零开始，严格推导从任意初始状态 $x_0$ 跳到任意时刻 $t$ 的分布。

### Step 1: 用重参数化重写一步转移

$$q(x_t|x_{t-1}) = \mathcal{N}(x_t; \sqrt{\alpha_t}x_{t-1}, (1-\alpha_t)I), \quad \alpha_t := 1 - \beta_t$$

重参数化：
$$\boxed{x_t = \sqrt{\alpha_t}\, x_{t-1} + \sqrt{1-\alpha_t}\,\epsilon_{t-1}, \quad \epsilon_{t-1} \sim \mathcal{N}(0,I)}$$

> **关键**：这和 VAE 的重参数化技巧一模一样！$x_{t-1}$ 是"均值"，$\sqrt{1-\alpha_t}$ 是"标准差"。

### Step 2: 递归展开——从 $x_0$ 直接到 $x_t$

让我们一步步展开：

$$\begin{aligned}
x_1 &= \sqrt{\alpha_1}\, x_0 + \sqrt{1-\alpha_1}\,\epsilon_0 \\
x_2 &= \sqrt{\alpha_2}\, x_1 + \sqrt{1-\alpha_2}\,\epsilon_1 \\
&= \sqrt{\alpha_2\alpha_1}\, x_0 + \sqrt{\alpha_2(1-\alpha_1)}\,\epsilon_0 + \sqrt{1-\alpha_2}\,\epsilon_1
\end{aligned}$$

继续展开：

$$x_t = \underbrace{\sqrt{\prod_{s=1}^t \alpha_s}}_{:=\bar{\alpha}_t^{1/2}} x_0 + \sum_{i=0}^{t-1} \left(\sqrt{1-\alpha_i}\cdot\sqrt{\prod_{s=i+1}^t \alpha_s}\right) \epsilon_i$$

其中约定 $\alpha_0 = 1$（第 0 步没有噪声），且定义累积乘积：
$$\boxed{\bar{\alpha}_t := \prod_{s=1}^t \alpha_s = \prod_{s=1}^t (1-\beta_s)}$$

### Step 3: 高斯线性变换 → 闭式表达式

由于 $x_t$ 是 $x_0$ 的线性变换加上独立高斯的和，它本身是高斯分布：

**均值**：
$$\mathbb{E}[x_t|x_0] = \sqrt{\bar{\alpha}_t}\, x_0 + 0 = \boxed{\sqrt{\bar{\alpha}_t}\, x_0}$$

**方差**：独立高斯的和的方差是方差的和。第 $i$ 项噪声 $\epsilon_i$ 的系数平方为 $(1-\alpha_i)\cdot\frac{\bar{\alpha}_t}{\bar{\alpha}_{i+1}}$，所以：
$$\text{Var}(x_t|x_0) = \sum_{i=0}^{t-1} (1-\alpha_i)\frac{\bar{\alpha}_t}{\bar{\alpha}_{i+1}}$$

注意到 $(1-\alpha_i)/\bar{\alpha}_{i+1}$ 是一个望远镜求和：
$$\begin{aligned}
\sum_{i=0}^{t-1}(1-\alpha_i)\frac{\bar{\alpha}_t}{\bar{\alpha}_{i+1}} &= \bar{\alpha}_t \sum_{i=0}^{t-1}\left(\frac{1}{\bar{\alpha}_{i+1}} - \frac{1}{\bar{\alpha}_{i+2}}\right) \quad (\text{其中 } \bar{\alpha}_{T+1}=1) \\
&= \bar{\alpha}_t \left(1-\bar{\alpha}_{t+1}/\bar{\alpha}_{t+1}\right)... 
\end{aligned}$$

等等，让我用更简洁的方式。直接计算系数平方和：

第 $i$ 项噪声的系数是 $c_i = \sqrt{1-\alpha_i}\cdot\sqrt{\frac{\bar{\alpha}_t}{\bar{\alpha}_{i+1}}}$，其平方为：
$$c_i^2 = (1-\alpha_i)\frac{\bar{\alpha}_t}{\bar{\alpha}_{i+1}}$$

而 $\bar{\alpha}_{i+1} = \alpha_{i+1}\bar{\alpha}_i$，所以：
$$c_i^2 = \frac{(1-\alpha_i)\bar{\alpha}_t}{\alpha_{i+1}\bar{\alpha}_i}$$

这个求和确实复杂。但有一个简洁结果——我们换个思路：直接用递归性质。

**更聪明的方法**：从 $x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1-\bar{\alpha}_t} \epsilon$ 直接定义！

为什么这样定义等价？因为如果我们设 $\text{Var}(x_t|x_0) = (1-\bar{\alpha}_t)$，则：
$$\boxed{q(x_t|x_0) = \mathcal{N}(x_t; \sqrt{\bar{\alpha}_t}\, x_0, (1-\bar{\alpha}_t)I)}$$

验证 $t=1$：$\bar{\alpha}_1 = \alpha_1 = 1-\beta_1$ → $\mathcal{N}(\sqrt{1-\beta_1}x_0, \beta_1 I)$ ✅，一步转移定义一致。

**boxed 核心公式**：
$$\boxed{q(x_t|x_0) = \mathcal{N}(x_t; \sqrt{\bar{\alpha}_t}\, x_0, (1-\bar{\alpha}_t)I), \quad \bar{\alpha}_t = \prod_{s=1}^t (1-\beta_s)}$$

### Step 4: 数值验证——手动计算 $x_t$ 的分布参数

设 $\beta_s = 0.02$（恒定方差调度），$T=1000$。

**计算 $\bar{\alpha}_{50}$**：
$$\bar{\alpha}_{50} = (1-0.02)^{50} = 0.98^{50} \approx e^{-0.02 \times 50} = e^{-1} \approx 0.3679$$

实际计算：$0.98^{50}$：
$$\boxed{\bar{\alpha}_{50} = 0.3642}$$

**因此 $x_{50}|x_0 \sim \mathcal{N}(0.6035\, x_0, 0.6358 I)$**。

> **直觉检查**：第 50 步（总步数 1000 的 5%），信号保留了约 $60\%$（$\sqrt{0.3642}$），噪声占 $64\%$。这符合"早期缓慢加噪"的设计意图——模型在早期看到的大部分还是原始数据。

### Step 5: 验证——独立重推

> **自测**：从以下事实出发，不看上面推导，能否得到 $q(x_t|x_0) = \mathcal{N}(\sqrt{\bar{\alpha}_t}\, x_0, (1-\bar{\alpha}_t)I)$？
> - 事实 1：$x_t = \sqrt{\alpha_t}x_{t-1} + \sqrt{1-\alpha_t}\,\epsilon_{t-1}$
> - 事实 2：高斯的线性变换仍是高斯，均值和方差可递推

**点击展开验证提示**：从 $x_0$ 出发，用数学归纳法。假设 $q(x_{t-1}|x_0) = \mathcal{N}(\sqrt{\bar{\alpha}_{t-1}}x_0, (1-\bar{\alpha}_{t-1})I)$，则：
<br><br>$x_t = \sqrt{\alpha_t}\cdot x_{t-1} + \text{噪声}$
<br>$E[x_t|x_0] = \sqrt{\alpha_t}\sqrt{\bar{\alpha}_{t-1}}x_0 = \sqrt{\bar{\alpha}_t}x_0$ ✅
<br>$\text{Var}(x_t|x_0) = \alpha_t(1-\bar{\alpha}_{t-1}) + (1-\alpha_t) = 1 - \alpha_t\bar{\alpha}_{t-1} = 1-\bar{\alpha}_t$ ✅

## 🧪 Part C: 数值示例——可视化加噪过程

### 设定

我们用一个简单的一维示例，追踪 $x_0=5.0$ 在加噪过程中的变化。

```python
import numpy as np

# 恒定方差调度 β = 0.02, T = 1000
T = 1000
beta = 0.02
alpha = 1 - beta
bar_alpha = [1.0]  # α_0 = 1

for t in range(1, T+1):
    bar_alpha.append(bar_alpha[-1] * alpha)

x0 = 5.0

# 计算关键时间点的分布参数
timesteps = [0, 10, 50, 100, 250, 500, 750, 900, 999]
print(f"{'t':>4} | {'α̅_t':>8} | '√α̅_t':>8} | 'σ_t':>8}")
print("-" * 45)
for t in timesteps:
    a_bar = bar_alpha[t]
    sqrt_a_bar = np.sqrt(a_bar)
    sigma_t = np.sqrt(1 - a_bar)
    mean_x = sqrt_a_bar * x0
    print(f"{t:>4} | {a_bar:>8.4f} | {sqrt_a_bar:>8.4f} | {sigma_t:>8.4f}")
```

## 💻 Part D: PyTorch 完整验证代码

```python
import torch
import torch.nn as nn

torch.manual_seed(42)

# ========== Diffusion 前向过程：闭式解验证 ==========

T = 1000
betas = torch.linspace(1e-4, 0.02, T)           # 线性方差调度
alphas = 1 - betas
sqrt_alphas = torch.sqrt(alphas)

# 累积乘积 α̅_t
bar_alphas = torch.cumprod(alphas, dim=0)
sqrt_bar_alphas = torch.sqrt(bar_alphas)
sigma_ts = torch.sqrt(1 - bar_alphas)

print("=== 方差调度验证 ===")
print(f"β_0 = {betas[0]:.6f}, β_{T-1} = {betas[-1]:.6f}")    # 1e-4 → 0.02 ✅
print(f"α̅_999 = {bar_alphas[-1]:.8f}")                         # ≈ 0 (完全加噪)

# ========== 方法对比：逐步模拟 vs 闭式解 ==========

x0 = torch.randn(64, 3, 64, 64)               # batch=64, RGB 64×64
t_sample = torch.randint(0, T, (64,))          # 随机采样时间步

# --- 方法 1: 逐步模拟（慢，但直观）---
x_t_simulated = x0.clone()
for t in range(1, T):
    noise = torch.randn_like(x_t_simulated)
    x_t_simulated = sqrt_alphas[t] * x_t_simulated + sigma_ts[t] * noise

# --- 方法 2: 闭式解（快，一次采样）---
# q(x_t|x_0) = N(√α̅_t · x_0, (1-α̅_t)I)
noise_direct = torch.randn_like(x0)
x_t_closed = sqrt_bar_alphas[t_sample].view(-1, 1, 1, 1) * x0 \
             + sigma_ts[t_sample].view(-1, 1, 1, 1) * noise_direct

# --- 验证：两种方法在给定 t 下应该一致 ---
t_test = 50                                     # 选一个特定时刻
mask_t = (t_sample == t_test)                   # 哪些样本是 t=50

if mask_t.sum() > 0:
    x_sim_at_50 = x_t_simulated[mask_t]
    x_closed_at_50 = x_t_closed[mask_t]
    
    diff = torch.abs(x_sim_at_50 - x_closed_at_50).mean().item()
    print(f"\n=== 闭式解验证 (t={t_test}) ===")
    print(f"逐步模拟 vs 闭式解的绝对误差均值: {diff:.2e}")
    
    # 理论上应该完全一致（因为用了相同的随机种子）
    if diff < 1e-10:
        print("✅ 两种方法输出完全一致！闭式解验证通过。")
    else:
        print(f"⚠️ 有差异（{diff:.2e}），可能是随机数不同导致的。")

# ========== SNR (信噪比) 分析 ==========

snr = bar_alphas / (1 - bar_alphas)             # Signal-to-Noise Ratio

print("\n=== SNR 随时间变化 ===")
for t in [0, 1, 5, 10, 20, 50, 100, 250, 500]:
    print(f"t={t:>4}: SNR = {snr[t].item():.4f}, √α̅_t = {sqrt_bar_alphas[t].item():.4f}")

# ✅ 关键观察：SNR 从无穷大（t=0）下降到接近零（t≈500），信号完全被噪声淹没
```

## 🗺️ Part E: Diffusion × 3DGS 衔接点

| Concept | 3DGS 对应 | 为什么重要 |
|---------|-----------|------------|
| **前向加噪 $q(x_t|x_{t-1})$** | Gaussian Splatting 的初始化和扰动 | 扩散：从数据到噪声；3DGS：从高斯初始化到最终渲染。两者都是"参数空间中的渐进变换"——但方向相反（一个破坏，一个构建） |
| **马尔可夫假设** | Alpha blending 的深度排序 | 扩散：$p(x_t|x_{t-1}, \ldots, x_0) = p(x_t|x_{t-1})$；3DGS：每个像素的 alpha blending 只依赖当前层和之前层的结果。两者都是局部依赖假设，简化了全局计算 |
| **累积乘积 $\bar{\alpha}_t$** | Gaussian Splatting 的 $c_i \cdot \prod (1-\alpha_j)$ | 扩散中的信号衰减因子 $\sqrt{\bar{\alpha}_t}$；3DGS 中透明度累积因子 $\prod_{j<i}(1-\alpha_j)$。两者都是"历史信息的压缩表示"——乘积形式让 T 步信息被一个值编码 |
| **闭式解 $q(x_t|x_0)$** | Volume Rendering 的离散化公式 | 扩散：不需要模拟 T 步，直接跳到 $t$；3DGS：不需要逐层渲染所有 Gaussian，alpha blending 公式给出闭合表达式。两者都通过数学推导避免了逐步骤计算 |

## 🎓 Part F: Summary

### 核心公式（必须记住）

$$\boxed{q(x_t|x_{t-1}) = \mathcal{N}(x_t; \sqrt{\alpha_t}\, x_{t-1}, (1-\alpha_t)I), \quad \alpha_t := 1-\beta_t}$$
$$\boxed{\bar{\alpha}_t = \prod_{s=1}^t \alpha_s,\quad q(x_t|x_0) = \mathcal{N}(x_t; \sqrt{\bar{\alpha}_t}\, x_0, (1-\bar{\alpha}_t)I)}$$

### Key Insights 💡

1. **马尔可夫 + 高斯 = 闭式解**：这是扩散模型最核心的数学红利。没有马尔可夫假设，$q(x_t|x_0)$ 需要做 $t-1$ 次卷积；有了它，只需一个公式。
2. **$\bar{\alpha}_t$ 是"信号保留率"**——从 $x_0$ 到 $x_t$，原始信息的比例是 $\bar{\alpha}_t = \prod_{s=1}^t (1-\beta_s)$。方差调度设计本质上是在控制这个衰减曲线的形状。
3. **一次性加噪 vs 逐步加噪**：暴力方案丢失了所有中间结构；扩散保留了从"几乎完整"到"纯噪声"的连续谱系——这正是反向去噪能够工作的基础。

## 📚 Part G: Exercises

### 🔰 Level 1: 基础题

**题目**：给定 $\beta_t = \frac{t}{T}$（线性递增调度），$T=1000$，计算 $t=100$ 时的 $\bar{\alpha}_{100}$ 和信噪比 SNR。

**💡 提示**：$\beta_t = t/1000$，所以 $\alpha_s = 1-s/1000$。<br>$\bar{\alpha}_{100} = \prod_{s=1}^{100}(1-s/1000) = \frac{999}{1000}\cdot\frac{998}{1000}\cdots\frac{900}{1000}$<br>近似：$\log \bar{\alpha}_{100} = \sum_{s=1}^{100}\log(1-s/1000) \approx -\sum s/1000 = -5050/1000 = -5.05$<br>$\bar{\alpha}_{100} \approx e^{-5.05}$

**答案**：$\bar{\alpha}_{100} \approx 0.0064$，SNR $= \frac{0.0064}{1-0.0064} \approx 0.0064$。信号几乎被噪声完全淹没（但这与恒定 $\beta$ 调度不同——递增 $\beta$ 意味着后期加噪更快）。

### 🚀 Level 2: 进阶题

**题目**：证明如果方差调度改为余弦形式 $\alpha_t = \cos^2\left(\frac{\pi t}{2T}\right)$，则 SNR 曲线更平滑。推导 $\bar{\alpha}_t$ 的解析表达式（提示：用三角恒等式）。

**💡 提示**：余弦调度的好处是前期加噪慢、后期快——与数据分布的自然结构匹配。<br><br>$\prod_{s=1}^t \cos^2(\frac{\pi s}{2T})$ 没有简洁闭式，但可以用数值积分近似：<br>$\log \bar{\alpha}_t = 2\sum_{s=1}^t \log\cos(\frac{\pi s}{2T}) \approx 2T\int_0^{t/T}\log\cos(\frac{\pi u}{2}) du$<br>这个积分有解析解（涉及 Clausen 函数），但实践中通常用数值累积乘积。

### 🔥 Level 3: 3DGS 关联题

**题目**：在 3DGS 训练中，我们有时会做"深度扰动"——对每个 Gaussian 的 $z$-center 加微小噪声来提高训练稳定性（类似数据增强）。考虑以下类比：

1. 扩散的前向过程是否可以看作对图像数据的"马尔可夫链式优化"？
2. $\bar{\alpha}_t$ 与 3DGS alpha blending 中的透明度累积有什么数学形式上的相似性？

**💡 提示**：<br>**1.** 是的！扩散的前向过程本质上是逐步"破坏"数据结构的马尔可夫链，这与优化过程中的"扰动搜索"有类比关系——两者都在参数/数据空间中进行渐进变换。<br><br>**2.** 数学形式完全相同：都是乘积形式。<br>- 扩散：$\bar{\alpha}_t = \prod_{s=1}^t (1-\beta_s)$ — 信号保留率<br>- 3DGS alpha blending：$T_i = \prod_{j<i}(1-\alpha_j)$ — 累积透明度<br>两者都是"历史信息通过乘积压缩为一个值"。这种结构使得 T 步操作可以用 O(1) 公式表达，而不是 O(T) 模拟。

### 🔮 Bonus: 直觉挑战

**问题**：为什么扩散模型不用 $\beta_t = \text{const}$（恒定方差），而要随时间变化？如果用恒定的大值（如 $\beta=0.5$）会发生什么？

**💡 提示**：$\beta=0.5$ 意味着每步 $\alpha=0.5$，所以 $\bar{\alpha}_t = 0.5^t$。这意味着：<br>- $t=1$: 信号只剩 $71\%$（$\sqrt{0.5}$）<br>- $t=10$: 信号只剩 $0.3\%$（几乎纯噪声）<br>- $T=1000$：瞬间变成纯噪声，中间没有有用的过渡态<br><br>反向去噪需要"从有结构的中间状态逐步恢复"，如果步数太少且每步扰动太大，模型无法学会有意义的去噪步骤。所以 $\beta_t$ 通常较小（0~0.02），让 T=1000 步能覆盖完整的信号→噪声连续谱系。
