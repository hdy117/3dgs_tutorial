# /first-principles-learn — 第一性原理学习（视觉学习者）

面向 **视觉学习者** 的第一性原理学习协议：不靠类比堆砌结论，而是 **拆到基石 → 自底向上重建 → 迁移检验**。

## Usage

```
/first-principles-learn [主题]
```

自然语言触发示例：
- 「用第一性原理教我反向传播」
- 「从第一性原理理解梯度下降」
- 「帮我用视觉化方式拆解这个概念」

## Before you start

1. 若主题模糊，先问 **最多 1–2 个** 澄清问题：学习目标、已有基础、希望深度（速览 / 标准 / 深入）。
2. 用户可指定只跑部分阶段（如「只拆基石」「只要迁移练习」）；否则 **默认跑完全部五阶段**。
3. 技术主题：可只读引用当前仓库代码/文档作为素材；非技术主题用日常例子。
4. 风格参考：`references/examples.md`（对齐输出节奏与视觉密度，勿照搬无关主题）。

## Core idea (keep this sharp)

| | 类比思维 | 第一性原理 |
|--|----------|------------|
| 起点 | 别人/课本怎么做 | 最基本的真是什么 |
| 方法 | 模仿与微调 | 拆到不可再拆，再向上推导 |
| 目标 | 会用一次 | 真懂 + 可迁移 |

禁止：用「因为行业都这么做」当作理由。必须回到 **定义、约束、物理/逻辑事实**。

## Visual learner rules (hard requirements)

- **每个阶段至少一种** 可「看见」的结构：Mermaid、ASCII 图、对比表、编号层级树。
- 优先 **短段落 + 图/表**；禁止墙式长文。
- 复杂对象：**先整体地图，再局部放大**。
- 隐喻（积木、水管、地图等）可以用，但 **必须映射回基石**，不能只讲故事。
- 全文用 **中文为主**；术语可中英并存（首次出现写清）。

## Five-stage protocol

按序执行。每阶段开头用标题 `## 阶段 N — …`。

```text
1. 定界问题 → 2. 拆到基石 → 3. 重建解法 → 4. 推广应用 → 5. 检验理解
         ↘ 每阶段：视觉图 / 表 / 流程 ↙
```

### 阶段 1 — 定界问题（基本问题）

回答并可视化：

- 要学/解决的是什么？成功标准是什么？
- 已知 vs 未知
- In scope / Out of scope（先学什么、故意不学什么）

**必选视觉**：问题卡片 + 边界表（或 Mermaid 框）。

### 阶段 2 — 拆到基石（第一性原理）

1. 列出 3–6 条常见 **类比/惯例假设**，逐条质疑。
2. 提炼 **3–7 条** 不可再拆的基本事实（定义、约束、公理）。
3. 每条基石用一句话说明「为什么成立 / 依据是什么」。

**必选视觉**（二选一或都用）：

- 三列表：假设 → 质疑 → 基石
- 金字塔：顶层结论 / 中层推导 / 底层公理

### 阶段 3 — 自底向上重建（如何提出解决方案）

1. **只用阶段 2 的基石** 推导，禁止跳步套结论。
2. 给出链条：`原理 → 中间结构 → 可操作步骤/知识结构`。
3. 推荐加一节对比：**类比做法 vs 第一性原理做法**。

**必选视觉**：推导流程图、决策树或架构草图（Mermaid 优先）。

### 阶段 4 — 推广应用（迁移）

1. 至少 **2 个** 新场景：换变量、换约束、或升一维难度。
2. 明确：哪些基石不变、哪些表象变了。
3. 每个场景给出「如何把同一基石用出去」的短步骤。

**必选视觉**：同一基石 → 多场景分叉图（Mermaid `flowchart` 或表）。

### 阶段 5 — 检验理解（闭环）

1. **费曼一页**：用更简单语言复述核心（3–5 句 + 一张总图）。
2. 给用户 **1–3 道** 小问题 / 反例 / 「若去掉某条基石会怎样」。
3. 若用户答错：回到阶段 2 补基石，**不要硬灌结论**。

**必选视觉**：检验清单或「基石 ↔ 考点」对照表。

## Output skeleton (default full run)

```markdown
# 第一性原理学习：{主题}

## 阶段 1 — 定界问题
… 图/表 …

## 阶段 2 — 拆到基石
… 假设质疑表 + 基石列表 + 金字塔/层级 …

## 阶段 3 — 自底向上重建
… 推导流程 + 可选对比表 …

## 阶段 4 — 推广应用
… 分叉图 + 2+ 场景 …

## 阶段 5 — 检验理解
… 费曼摘要 + 小问题 …

## 一页速览
- 基石（bullet）
- 一张总图（Mermaid）
- 一条迁移提示
```

## Partial-run modes

| 用户意图 | 执行 |
|----------|------|
| 只拆基石 / 质疑假设 | 阶段 1–2 |
| 只要解法推导 | 阶段 2–3（可简述 1） |
| 只要迁移 / 应用 | 阶段 2 摘要 + 4 |
| 考考我 / 检验 | 阶段 2 摘要 + 5 |

## Anti-patterns

- 堆砌名词与公式却不回到基石
- 只有类比故事，没有「不可再拆的事实」
- 给结论却跳过推导链
- 无任何图/表的纯长文
- 迁移场景与基石无关（伪应用）

## After completion

告诉用户可以：
- 指定新主题再跑一轮
- 针对某阶段加深（如「只把阶段 2 拆得更细」）
- 用阶段 5 的问题作自测，答完后继续批改
