## 📐 Part 1: 期望（Expectation）— 加权平均

### 直观理解：期望 = "长期平均" + 一个生活例子

**掷骰子实验**：
- 掷 6000 次，每个面大约出现 1000 次
- 平均值 ≈ (1+2+3+4+5+6)/6 = **3.5**

这就是期望！即使你永远不会掷出"3.5"点——它是**理论上的长期平均**。

### 💡 生活例子：彩票的期望收益

想象一张彩票售价 2 元，中奖规则如下：
- 一等奖（1/10,000,000）：奖金 5,000,000 元
- 二等奖（1/1,000,000）：奖金 10,000 元
- 其他情况（几乎必然）：奖金 0 元

**期望收益** = 每个结果的奖金 × 对应概率之和：
$$E[\text{收益}] = \frac{1}{10^7} \times 5,000,000 + \frac{1}{10^6} \times 10,000 + (1 - \frac{1}{10^7} - \frac{1}{10^6}) \times 0$$
$$= 0.5 + 0.01 = \boxed{0.51 \text{ 元}}$$

**结论**：每买一张彩票，你平均"期望收回"0.51 元。但票价是 2 元 → **净亏损 1.49 元/张**。这就是为什么庄家永远赚钱 — 期望收益对玩家永远是负的！

> 🎯 **关键直觉**：期望不是"最可能出现的值"，而是"**如果你做无数次的平均结果**"。买一次彩票你不会得到 0.51 元（你要么得 0、要么得 10,000、要么得 5M），但如果你买一百万张，总收入 / 一百万 ≈ 510 元 ≈ 0.51 × 10^6。

### 离散型：加权求和

$$\boxed{E[X] = \sum_k x_k \cdot p(x_k)}$$

每个取值 $x_k$ 乘以它的概率权重，加起来。

**推导**（从大数定律的直觉出发）：
- 掷 N 次骰子，第 k 面出现约 $N \cdot p(k)$ 次
- 总和 ≈ $\sum_k x_k \cdot (N \cdot p(k))$
- 平均 = 总和/N ≈ $\sum_k x_k \cdot p(k) = E[X]$ ∎

### 连续型：加权积分

$$\boxed{E[X] = \int_{-\infty}^{\infty} x \cdot f_X(x)\,dx}$$

PDF $f(x)$ 代替 PMF，求和变积分。

## 🔥 Part 2: 期望的三大性质（从线性性开始）

### 性质 1：线性性 — "期望不会骗人"

$$\boxed{E[aX + bY + c] = aE[X] + bE[Y] + c}$$

**推导**：

离散型证明：
$$\begin{aligned}
E[aX + bY + c] &= \sum_{x,y} (ax + by + c) \cdot P(X=x, Y=y) \\
&= a\sum_{x,y} x \cdot P(X=x, Y=y) + b\sum_{x,y} y \cdot P(X=x, Y=y) + c\sum_{x,y} P(X=x, Y=y) \\
&= aE[X] + bE[Y] + c
\end{aligned}$$

最后一个等号用了：$\sum_x P(X=x) = 1$（边际概率归一化）。

**连续型同理，求和变积分。**

### 💡 为什么线性性重要？3DGS 中的直接应用

渲染公式是线性的：
$$C_{\text{pixel}} = \sum_i w_i c_i, \quad \text{其中 } w_i \text{ 是 Splat i 的权重}$$

期望也是线性的，所以：
$$E[C_{\text{pixel}}] = \sum_i E[w_i] \cdot c_i$$

**这意味着：你可以"先算每个Splat的平均贡献，再加起来"** — 简化了大量计算。这也是为什么 PyTorch 的 autograd 能高效处理期望类运算。

### 性质 2：常数期望 = 它自己

$$E[c] = c$$

 trivial but foundational — 不变量在取平均后还是不变量。

### 性质 3：Jensen 不等式（凸函数的"陷阱"） + 💡 具体例子

如果 $g(\cdot)$ 是**凸函数**，则：
$$\boxed{g(E[X]) \leq E[g(X)]}$$

- 凸函数例子：$x^2$, $\exp(x)$, $-\log(x)$ — **这些都是 ML 里的 loss function！**
- 这意味着：**平均值的函数 ≠ 函数的平均值**，前者更小。

### 💡 生活例子：你的"平均收入" vs "收入的平均值"

想象你和三个朋友讨论年收入（单位：万元）：

| 人 | 年收入 X |
|----|---------|
| Alice | 50 |
| Bob | 60 |
| Charlie | 70 |
| Dave | 200 (创业成功了！) |

**步骤1 — 计算平均收入（期望）**：
$$E[X] = \frac{50+60+70+200}{4} = \boxed{95 \text{ 万}}$$

**步骤2 — 先平方再求平均（E[g(X)]，其中 g(x)=x²）**：
$$E[X^2] = \frac{50^2 + 60^2 + 70^2 + 200^2}{4} = \frac{2500+3600+4900+40000}{4} = \boxed{12,750}$$

**步骤3 — 平均值的平方（g(E[X])）**：
$$g(E[X]) = E[X]^2 = 95^2 = \boxed{9,025}$$

**Jensen 不等式验证**：$g(E[X]) \leq E[g(X)]$ → $9,025 \leq 12,750$ ✅

> 🎯 **关键直觉**：为什么 $E[X^2] > (E[X])^2$？因为 Dave 的 200 万被平方成了 40,000 — **大值在平方时被极大地放大了**，而小值（50²=2500）贡献很小。所以"先平方再平均"比"先平均再平方"要大得多！这个差异正好就是方差：$\text{Var}(X) = E[X^2] - (E[X])^2 = 12,750 - 9,025 = 3,725$。

- 这意味着：**平均值的函数 ≠ 函数的平均值**，前者更小。

**直观理解**：取平方会"放大"远离均值的点（因为平方后大偏差被夸大了）。所以 $E[X^2] \geq (E[X])^2$ — 这直接引出方差！

## 📐 Part 3: 方差与标准差 — "波动的尺度"

### 💡 生活例子：两个投资人的选择

假设你有两种投资方案，预期年化收益都是 **10%**（期望相同）：

| 方案 | 收益分布 |
|------|---------|
| A — 银行理财 | 9.5% ~ 10.5%（几乎确定） |
| B — 创业股票 | -30% ~ +70%（大起大落） |

**期望相同，但谁更"安全"？** 答案是方差！

- **方案 A**：收益几乎围绕 10% 小幅波动 → 方差极小（≈ 0.25² = 0.0625）
- **方案 B**：收益从 -30% 到 +70%，跨度达 100 个点 → 方差极大（≈ (40)² = 1600）

> 🎯 **直觉理解**：方差回答的是"偏离典型值有多远"。同样的平均值，一个稳定如银行、一个波动如过山车——这就是方差的威力：**它刻画了不确定性的大小**。

### 💡 第二个例子：射击运动员的稳定性

两名射手各射了 10 箭，环数记录如下：
- **射手甲**：[9, 10, 9, 10, 10, 9, 10, 9, 10, 10] → 平均 = 9.5
- **射手乙**：[3, 10, 7, 10, 2, 10, 8, 10, 5, 10] → 平均 = 7.5

等等，如果我们只看期望（平均环数），甲比乙强。但如果我们看方差：
- **甲的方差** ≈ 0.25 — 成绩极其稳定
- **乙的方差** ≈ 9.05 — 成绩忽高忽低（有时打中靶心，有时脱靶）

在射击比赛中，如果你需要"可靠地打出高分"，你会选择甲——因为他的期望更高且方差更小。这就像 3DGS 中的 Splat：你需要一个**期望位置准确（μ）且扩散范围可控（Σ）**的高斯，而不是一个"平均位置对但偶尔疯狂偏移"的 Splat！

### 定义：期望的平方距离

$$\boxed{\text{Var}(X) = E[(X - E[X])^2]}$$

**直觉**：每个取值偏离均值的程度（取绝对值太简单，用平方更数学友好），再对概率加权平均。

### 展开公式（计算神器）

$$\begin{aligned}
\text{Var}(X) &= E[(X - \mu)^2] \quad (\mu = E[X]) \\
&= E[X^2 - 2\mu X + \mu^2] \\
&= E[X^2] - 2\mu E[X] + \mu^2 \\
&= E[X^2] - 2\mu^2 + \mu^2 \\
&= \boxed{E[X^2] - (E[X])^2}
\end{aligned}$$

**记住这个公式！** `方差 = 平方的期望 − 期望的平方`。计算方便多了——不用先算均值再算每个偏差。

### 标准差：方差的"开根号"，回到原单位

$$\boxed{\sigma_X = \sqrt{\text{Var}(X)}}$$

- 方差单位是 $X^2$（比如 "像素²"），难以直觉理解
- 标准差单位与 X 相同（"像素"），可以直接说"偏离均值约 ±σ"

## 🔥 Part 4: 高斯分布的期望和方差 — 从定义推导

### 目标：验证 $X \sim N(\mu, \sigma^2)$ 时，$E[X] = \mu$, $\text{Var}(X) = \sigma^2$

**期望推导**（连续型）：
$$\begin{aligned}
E[X] &= \int_{-\infty}^{\infty} x \cdot \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}\,dx \\
\text{令 } u = x - \mu &\Rightarrow x = u + \mu \\
&= \int_{-\infty}^{\infty} (u + \mu) \cdot \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{u^2}{2\sigma^2}}\,du \\
&= \underbrace{\int u \cdot f(u)\,du}_{=0,\text{奇函数对称积分}} + \mu \underbrace{\int f(u)\,du}_{=1} \\
&= \boxed{\mu} \quad ∎
\end{aligned}$$

**方差推导**：
$$\begin{aligned}
E[X^2] &= \int_{-\infty}^{\infty} x^2 \cdot f(x)\,dx = \int (u+\mu)^2 f(u)\,du \\
&= E[u^2] + 2\mu E[u] + \mu^2 = E[u^2] + \mu^2
\end{aligned}$$

其中 $u \sim N(0, \sigma^2)$，所以 $E[u^2] = \text{Var}(u) = \sigma^2$。因此：
$$\boxed{\text{Var}(X) = E[X^2] - (E[X])^2 = (\sigma^2 + \mu^2) - \mu^2 = \sigma^2} \quad ∎$$

## 🧪 Part 5: 数值示例 — Boxed Result

### 案例：3DGS 中的像素颜色不确定性

假设某个像素由两个 Splat 贡献，权重是随机变量：
- $W_1 \sim$ 伯努利(0.6)，即 $P(W_1=1)=0.6, P(W_1=0)=0.4$
- $W_2 = 1 - W_1$（互斥）

颜色：$C = W_1 c_1 + (1-W_1) c_2$，其中 $c_1 = [0.5, 0.3, 0.7]$，$c_2 = [0.8, 0.6, 0.4]$

**计算期望**：
$$\boxed{E[C] = E[W_1] c_1 + (1 - E[W_1]) c_2}$$

其中 $E[W_1] = 1 \cdot 0.6 + 0 \cdot 0.4 = 0.6$，所以：
$$\boxed{E[C] = 0.6 \cdot [0.5, 0.3, 0.7] + 0.4 \cdot [0.8, 0.6, 0.4] = [0.62, 0.42, 0.58]}$$

**计算方差**（对每个通道）：
$$\text{Var}(W_1) = E[W_1^2] - (E[W_1])^2 = 0.6 - 0.36 = 0.24$$
$$\boxed{\text{Var}(C_{\text{R}}) = c_{1R}^2 \cdot \text{Var}(W_1) + c_{2R}^2 \cdot \text{Var}(1-W_1)}$$

由于 $\text{Var}(aX+b) = a^2\text{Var}(X)$，且 $1-W_1$ 的方差与 $W_1$ 相同：
$$\boxed{\text{Var}(C_{\text{R}}) = (0.5 - 0.8)^2 \cdot 0.24 = (-0.3)^2 \cdot 0.24 = 0.0216}$$

## 💻 Part 6: PyTorch 验证

```python
import torch
import math

# ============================================================
# 1. 离散型：伯努利分布的期望和方差
# ============================================================
p = 0.6
w = torch.tensor([0, 1], dtype=torch.float32)
pmf = torch.tensor([1 - p, p])

E_W = (w * pmf).sum()          # E[X]
E_W2 = (w**2 * pmf).sum()      # E[X²]
Var_W = E_W2 - E_W**2           # Var(X)

print(f"伯努利(p={p}):")
print(f"  E[W]    = {E_W.item():.4f}   (理论: {p})")
print(f"  Var(W)  = {Var_W.item():.4f}   (理论: {p*(1-p)})")

# ============================================================
# 2. 连续型：高斯分布的期望和方差（数值积分验证）
# ============================================================
mu, sigma = 3.0, 2.0
x = torch.linspace(mu - 5*sigma, mu + 5*sigma, 100000)
pdf_normal = (1 / (math.sqrt(2 * math.pi) * sigma)) * \
             torch.exp(-0.5 * ((x - mu) / sigma)**2)

dx = x[1] - x[0]
E_X_numeric = (x * pdf_normal).sum() * dx
E_X2_numeric = (x**2 * pdf_normal).sum() * dx
Var_X_numeric = E_X2_numeric - E_X_numeric**2

print(f"\n高斯 N({mu}, {sigma}²):")
print(f"  E[X]    = {E_X_numeric.item():.4f}   (理论: {mu})")
print(f"  Var(X)  = {Var_X_numeric.item():.4f}   (理论: {sigma**2})")

# ============================================================
# 3. 用 PyTorch Distributions API（最简洁）
# ============================================================
from torch.distributions import Normal, Bernoulli

normal = Normal(torch.tensor(mu), torch.tensor(sigma))
bern = Bernoulli(torch.tensor(p))

print(f"\nPyTorch Distributions:")
print(f"  Normal: E={normal.mean.item():.4f}, Var={normal.variance.item():.4f}")
print(f"  Bernoulli: E={bern.mean.item():.4f}, Var={bern.variance.item():.4f}")

# ============================================================
# 4. 线性性验证：E[aX + bY] = aE[X] + bE[Y]
# ============================================================
a, b = 2.0, -1.5
X_sim = normal.sample((10000,))
Y_sim = bern.sample((10000,))

E_linear = (a * X_sim + b * Y_sim).mean()
E_formula = a * normal.mean + b * bern.mean

print(f"\n线性性验证:")
print(f"  E[2X - 1.5Y] via simulation: {E_linear.item():.4f}")
print(f"  E[2X - 1.5Y] via formula:    {E_formula.item():.4f}")
print(f"  差值: {abs(E_linear - E_formula).item():.6e}")  # → ~1e-3 (采样误差)

# ============================================================
# 5. Jensen 不等式验证：E[X²] ≥ (E[X])²
# ============================================================
print(f"\nJensen 不等式验证:")
print(f"  E[X²] = {E_X2_numeric.item():.4f}")
print(f"  (E[X])² = {E_X_numeric.item()**2:.4f}")
print(f"  E[X²] ≥ (E[X])²? → {E_X2_numeric >= E_X_numeric**2} ✅")
```

## 📐 Part 7: 高阶矩 — 偏度与峰度（简要）

### 偏度（Skewness）：分布的"倾斜程度"

$$\boxed{\text{Skew}(X) = \frac{E[(X - \mu)^3]}{\sigma^3}}$$

- Skew > 0: 右尾更长（正偏，均值 > 中位数）
- Skew < 0: 左尾更长（负偏）
- **高斯分布的偏度 = 0**（完美对称）

### 峰度（Kurtosis）：分布的"尖峭程度"

$$\boxed{\text{Kurt}(X) = \frac{E[(X - \mu)^4]}{\sigma^4}}$$

- Kurt > 3: 比高斯更尖锐、尾部更重
- Kurt < 3: 比高斯更平坦
- **高斯分布的峰度 = 3**（"正态峰度"）

## 🗺️ Part 8: 与 3DGS 的衔接点

| 概念 | 3DGS 对应 | 为什么重要 |
|------|-----------|-----------|
| **期望 E[X]** | Gaussian Splat 的均值位置 μ | 你看到的"高斯中心"就是期望值 |
| **方差 σ²** | Gaussian Splat 的协方差矩阵 Σ | 控制 Splat 的"扩散程度" — 大方差 = 模糊，小方差 = 锐利 |
| **线性性 E[aX+bY]** | Alpha blending $\sum w_i c_i$ | 渲染是线性的 → 期望和渲染可交换顺序 |
| **高斯分布** | Splat 的形状函数 | 中心极限定理：大量微小随机效应（传感器噪声、采样误差）→ 自然高斯形状 |

## 🎓 本章小结

### 核心公式（必须记住的 3 个）

$$\boxed{\begin{aligned}
E[X] &= \sum_k x_k p(x_k) \quad (\text{离散}) \\
&= \int x f(x)\,dx \quad (\text{连续})
\end{aligned}}$$

$$\boxed{\text{Var}(X) = E[(X-\mu)^2] = E[X^2] - (E[X])^2}$$

$$\boxed{\text{高斯 } N(\mu,\sigma^2):\ E[X]=\mu,\ \text{Var}(X)=\sigma^2}$$

### 关键洞察

> **期望不是"最可能出现的值"** —— 它是加权平均。掷骰子的期望是 3.5，但你永远掷不出 3.5。
> 
> **方差 = 平方的期望 - 期望的平方** — 这个公式让计算变得 O(1)，不用遍历每个偏差项。
> 
> **线性性**：$E[aX+bY+c] = aE[X]+bE[Y]+c$ — 不需要 X,Y 独立！这是 ML 中最强大的工具之一。
