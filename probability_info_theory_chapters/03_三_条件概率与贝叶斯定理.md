## 🎯 问题驱动：条件概率 — "缩小世界"的艺术

### 场景 1：调试一个模糊的像素

```python
# 你看到渲染图中某个像素非常红
observed_color = [0.92, 0.15, 0.12]  # 明显偏红

# 现在你要推断：是哪个 Splat 贡献了这个颜色？
# 有 3 个候选 Splat: A（红色涂料）, B（棕色物体）, C（阴影中的红色）
```

**关键问题**：给定"像素是红色的"这个观测，每个 Splat 是来源的概率是多少？

### 答案：条件概率 — "在缩小世界里重新计算概率"

**直觉**：条件概率 $P(B|A)$ = **"已知 A 发生了之后，B 发生的概率"**。

操作方式：**把样本空间从"所有可能"缩小到"A 发生的那些情况"**，然后重新归一化概率。

---

## 📐 Part 1: 条件概率的定义

### 核心公式

$$\boxed{P(A|B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0}$$

**推导思路**（从直觉出发）：

1. 原始世界：所有可能的结果 Ω，总概率 = 1
2. 已知 B 发生：样本空间缩小为 $B$，其中 $P(B)$ 不再等于 1
3. A 在缩小后的世界中发生的概率 = "A 和 B 同时发生"的部分 / "B 发生"的部分

$$\boxed{\text{条件概率} = \frac{\text{交集}}{\text{已知事件}}}$$

### 三个等价理解

| 视角 | 公式 | 直觉 |
|------|------|------|
| **频率论** | $P(A|B) ≈ \frac{n(A \cap B)}{n(B)}$ | "在 B 发生的那些试验中，A 占多少比例？" |
| **概率论** | $P(A|B) = \frac{P(A \cap B)}{P(B)}$ | 缩放归一化 |
| **贝叶斯** | $P(A|B) ∝ P(B|A)·P(A)$ | 用似然更新先验 |

## 🧪 Part 2: 数值示例 — Boxed Result

### 案例：像素来源推断

假设有 3 个 Splat，每个在某个像素处"主导"的概率（先验）为：
$$P(S_1) = 0.5, \quad P(S_2) = 0.3, \quad P(S_3) = 0.2$$

如果 Splat $S_i$ 是来源，它产生红色像素的条件概率为：
$$P(\text{Red}|S_1) = 0.8,\quad P(\text{Red}|S_2) = 0.1,\quad P(\text{Red}|S_3) = 0.4$$

**问题**：已知像素是红色的，每个 Splat 是来源的后验概率是多少？

### 解法：贝叶斯定理（下一章详细推导）先给答案

$$P(S_i|\text{Red}) = \frac{P(\text{Red}|S_i) \cdot P(S_i)}{\sum_j P(\text{Red}|S_j) \cdot P(S_j)}$$

分母（全概率公式）：
$$\boxed{P(\text{Red}) = 0.8 \times 0.5 + 0.1 \times 0.3 + 0.4 \times 0.2 = 0.40 + 0.03 + 0.08 = 0.51}$$

后验概率：
$$\boxed{\begin{aligned}
P(S_1|\text{Red}) &= \frac{0.8 \times 0.5}{0.51} = \frac{0.40}{0.51} \approx 0.784 \\
P(S_2|\text{Red}) &= \frac{0.1 \times 0.3}{0.51} = \frac{0.03}{0.51} \approx 0.059 \\
P(S_3|\text{Red}) &= \frac{0.4 \times 0.2}{0.51} = \frac{0.08}{0.51} \approx 0.157
\end{aligned}}$$

**验证归一化**：$0.784 + 0.059 + 0.157 = 1.000$ ✅

## 🔥 Part 3: 贝叶斯定理 — 从第一性原理推导

### 目标公式

$$\boxed{P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}}$$

### 推导过程（3 步，从定义出发）

**Step 1 — 对称条件概率**：
由定义，同时有：
$$P(A|B) = \frac{P(A \cap B)}{P(B)}, \quad P(B|A) = \frac{P(B \cap A)}{P(A)}$$

注意 $P(A \cap B) = P(B \cap A)$（交集是对称的）。

**Step 2 — 交叉相乘得到联合概率**：
$$P(A \cap B) = P(A|B) \cdot P(B) = P(B|A) \cdot P(A)$$

这就是**乘法法则**！它告诉你：**两个事件同时发生的概率 = 一个条件 × 另一个边缘**。

**Step 3 — 解出 $P(A|B)$**：
$$\boxed{P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}} \quad ∎$$

### 工程解读：贝叶斯定理的三要素

| 术语 | 公式 | 含义 | 3DGS 类比 |
|------|------|------|-----------|
| **先验** $P(A)$ | 更新前 | "在没有观测之前，你的信念" | Splat 的初始权重（深度排序决定） |
| **似然** $P(B|A)$ | 模型 | "如果 A 是真的，看到 B 的可能性多大？" | Splat i 产生颜色 c 的概率（由高斯 PDF 给出） |
| **后验** $P(A|B)$ | 更新后 | "观测到 B 之后，A 是真的概率" | 根据像素颜色推断哪个 Splat 主导 |

## 🔥 Part 4: 全概率公式 — 贝叶斯的"分母怎么算"

### 问题：$P(B)$ 怎么求？如果不知道所有可能情况呢？

**答案**：假设 $A_1, A_2, ..., A_n$ 构成一个**划分（partition）**——互斥且覆盖所有可能。

$$\boxed{P(B) = \sum_{i=1}^{n} P(B|A_i) \cdot P(A_i)}$$

**推导**：
- $B = B \cap \Omega = B \cap (\bigcup_i A_i) = \bigcup_i (B \cap A_i)$
- 由于 $A_i$ 互斥，$(B \cap A_i)$ 也互斥
- 概率的可加性 → 求和

### 💡 3DGS 中的全概率公式

渲染中的像素颜色是一个连续随机变量 $C$。给定 N 个 Splat：
$$P(C_{\text{pixel}} = c) = \sum_{i=1}^{N} P(C_{\text{pixel}} = c | \text{Splat}_i\text{主导}) \cdot P(\text{Splat}_i\text{主导})$$

其中：
- $P(\text{Splat}_i\text{主导})$ 由 alpha blending 的累积权重 $\alpha_i \prod_{j<i}(1-\alpha_j)$ 给出
- $P(C_{\text{pixel}} = c | S_i)$ 由高斯 PDF 在位置 c 处的密度值决定

## 📐 Part 5: 独立性 — "互不相干"的数学定义

### 定义

$$\boxed{A \text{ 和 } B \text{ 独立} \iff P(A \cap B) = P(A) \cdot P(B)}$$

等价地：$P(A|B) = P(A)$（知道 B 不影响 A 的概率）

### 期望的独立性性质

如果 X, Y 独立：
$$\boxed{E[XY] = E[X] \cdot E[Y]}$$

**推导**：
联合 PMF/PDF 因式分解：$p(x,y) = p_X(x) \cdot p_Y(y)$，所以：
$$E[XY] = \sum_{x,y} xy \cdot p(x,y) = \left(\sum_x x \cdot p_X(x)\right) \cdot \left(\sum_y y \cdot p_Y(y)\right) = E[X] \cdot E[Y]$$

### 方差的独立性性质（重要！）

如果 X, Y 独立：
$$\boxed{\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y)}$$

**注意**：没有这个性质的话，$\text{Var}(X+Y) = \text{Var}(X)+\text{Var}(Y)+2\text{Cov}(X,Y)$（协方差项）。独立性让交叉项消失。

## 💻 Part 6: PyTorch 验证

```python
import torch
import math

# ============================================================
# 1. 条件概率：贝叶斯定理数值验证
# ============================================================
print("=== 贝叶斯定理验证 ===")

# 先验和似然
prior = torch.tensor([0.5, 0.3, 0.2])           # P(S_i)
likelihood = torch.tensor([0.8, 0.1, 0.4])      # P(Red|S_i)

# 联合概率（分子）：P(Red, S_i) = P(Red|S_i) * P(S_i)
joint = likelihood * prior                        # [0.40, 0.03, 0.08]

# 全概率公式 → 边缘概率 P(Red)
evidence = joint.sum()                            # P(Red) = 0.51

# 后验：P(S_i|Red) = P(Red,S_i) / P(Red)
posterior = joint / evidence

print(f"先验:     {prior}")
print(f"似然:     {likelihood}")
print(f"联合概率: {joint}")
print(f"P(Red)    = {evidence.item():.4f}  （全概率公式）")
print(f"后验:     {posterior}")
print(f"后验求和: {posterior.sum().item():.6f}  → ✅ 归一化")

# ============================================================
# 2. 独立性验证：E[XY] = E[X]·E[Y]（当 X,Y 独立时）
# ============================================================
print("\n=== 独立性验证 ===")

# 生成两个独立的伯努利变量
X = torch.bernoulli(torch.tensor([0.7])).repeat(10000)       # P(X=1)=0.7
Y = torch.bernoulli(torch.tensor([0.3])).repeat(10000)       # P(Y=1)=0.3

E_XY_sim = (X * Y).mean()
E_XY_formula = X.mean() * Y.mean()

print(f"E[XY] 模拟: {E_XY_sim.item():.4f}")
print(f"E[X]·E[Y]:  {E_XY_formula.item():.4f}")
print(f"理论值:     {0.7*0.3:.4f} （因为 P(X=1,Y=1) = 0.7×0.3）")

# ============================================================
# 3. 独立性 vs 非独立性的方差对比
# ============================================================
print("\n=== Var(X+Y): 独立 vs 相关 ===")

X2 = torch.randn(10000)  # N(0,1)
Y2_independent = torch.randn(10000)   # 独立的 N(0,1)
Y2_dependent = X2 + torch.randn(10000) * 0.5  # 相关的（加了 X2）

# 独立情况
var_sum_indep = (X2 + Y2_independent).var()
var_x_plus_var_y = X2.var() + Y2_independent.var()

# 相关情况
var_sum_dep = (X2 + Y2_dependent).var()

print(f"Var(X+Y_indep)   = {var_sum_indep.item():.4f}")
print(f"Var(X)+Var(Y_indep)= {var_x_plus_var_y.item():.4f}  → 相等 ✅")
print(f"\nVar(X+Y_dependent) = {var_sum_dep.item():.4f}")
print(f"Var(X)+Var(Y_dependent) = {(X2.var() + Y2_dependent.var()).item():.4f}")
print(f"  → 不相等！差了协方差项")

# ============================================================
# 4. 高斯分布的条件概率（3DGS 的核心）
# ============================================================
from torch.distributions import Normal, MultivariateNormal

print("\n=== 多元高斯条件概率 ===")

# 一维条件：已知 X=x，Y 的分布是什么？
mu = torch.tensor([0.0, 1.0])          # [μ_x, μ_y]
sigma = torch.tensor([[1.0, 0.5],      # Σ = [[σ²_x, ρ·σ_x·σ_y],
                      [0.5, 2.0]])     #         [ρ·σ_x·σ_y, σ²_y]]

mvn = MultivariateNormal(mu, sigma)

# 条件分布公式：Y|X=x ~ N(μ_{y|x}, Σ_{y|x})
# μ_{y|x} = μ_y + ρ·(σ_y/σ_x)·(x - μ_x)
# Σ_{y|x} = σ²_y · (1 - ρ²)

rho = 0.5 / math.sqrt(1.0 * 2.0)      # 相关系数
mu_cond = mu[1] + rho * math.sqrt(2.0/1.0) * (1.0 - mu[0])  # y|x=1
var_cond = 2.0 * (1 - rho**2)

print(f"给定 X=1，Y|X~N({mu_cond:.4f}, {var_cond:.4f})")

# 验证：用采样估计条件分布
samples = mvn.sample((50000,))
mask = torch.abs(samples[:, 0] - 1.0) < 0.05  # X ≈ 1
if mask.sum() > 0:
    y_cond_sampled = samples[mask, 1]
    print(f"采样估计: Y|X≈1 ~ N({y_cond_sampled.mean():.4f}, {y_cond_sampled.var():.4f})")

# ============================================================
# 5. PyTorch Distributions 中的条件操作
# ============================================================
from torch.distributions import Categorical

print("\n=== Categorical 的条件采样 ===")

weights = torch.tensor([0.5, 0.3, 0.2])
cat = Categorical(weights)

# 在已知某条件下更新权重（贝叶斯后验）
conditioning_evidence = torch.tensor([0.8, 0.1, 0.4])
posterior_weights = weights * conditioning_evidence
posterior_cat = Categorical(posterior_weights / posterior_weights.sum())

samples = posterior_cat.sample((5000,))
freq = torch.stack([(samples == i).float().mean() for i in range(3)])
print(f"后验采样频率: {freq}")
print(f"理论后验:     {posterior_weights / posterior_weights.sum()}")
```

## 🗺️ Part 7: 与 3DGS 的衔接点

| 条件概率概念 | 3DGS 中的对应 | 具体用法 |
|-------------|---------------|----------|
| **$P(A|B)$** | "给定 Splat i，像素颜色是 c 的概率" | 由高斯 PDF $N(c; \mu_i, \Sigma_i)$ 给出 |
| **贝叶斯后验** | 根据观测像素反向推断场景参数 | 用于不确定性量化、鲁棒渲染（去掉异常值） |
| **全概率公式** | $\sum_i \alpha_i \prod_{j<i}(1-\alpha_j) c_i$ | 每个 Splat 的贡献权重之和 = 总概率归一化 |
| **条件高斯** | Gaussian 的参数本身有不确定性 | 优化后的 μ, Σ 可以看作后验分布的均值和协方差 |

## 🎓 本章小结

### 核心公式（三个必须记住）

$$\boxed{P(A|B) = \frac{P(A \cap B)}{P(B)}}$$

$$\boxed{P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)} \quad \text{（贝叶斯定理）}}$$

$$\boxed{P(B) = \sum_i P(B|A_i) \cdot P(A_i) \quad \text{（全概率公式，$\{A_i\}$ 为划分）}}$$

### 关键洞察

> **条件概率 = "缩小样本空间"的归一化操作** —— 不是新规则，只是在更小的世界里重新计算比例。
> 
> **贝叶斯定理的本质**：$P(A|B) ∝ P(B|A) \cdot P(A)$ — 后验与先验×似然的乘积成正比。归一化常数 $P(B)$ 只是确保总和为 1。
> 
> **独立性 = 可因式分解** —— $p(x,y) = p_X(x)p_Y(y)$，这让联合期望/方差可以拆成边缘的运算。3DGS 中假设不同 Splat 的颜色噪声独立，简化了大量计算。

条件概率和贝叶斯是"推理的工具箱"，但工具箱需要具体的"零件"——也就是各种分布。下一章我们将深入**高斯分布、伯努利分布、多项式分布**及其共轭先验 Beta 和 Dirichlet — 它们都是 3DGS 中直接用到的核心分布。

- (a) $P(A|B)$
- (b) $P(B|A)$
- (c) $P(A \cup B)$

<details>
<summary>💡 提示</summary>
(a) $P(A|B) = \frac{0.2}{0.5} = \boxed{0.4}$（注意这里 A,B 独立！$P(A∩B)=P(A)·P(B)$）
(b) $P(B|A) = \frac{0.2}{0.4} = \boxed{0.5}$
(c) $P(A∪B) = P(A)+P(B)-P(A∩B) = 0.4+0.5-0.2 = \boxed{0.7}$（容斥原理）
</details>

**3.2** 证明贝叶斯定理的对称性：$P(A|B)·P(B) = P(B|A)·P(A)$。

<details>
<summary>💡 提示</summary>
两者都等于 $P(A \cap B)$，由条件概率定义直接得出。这就是联合概率的两个等价表达。
</details>
