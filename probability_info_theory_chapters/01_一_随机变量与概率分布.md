# Ch01 — 随机变量与概率分布：从"掷骰子"到"3DGS 的高斯参数"

> **本章目标**：搞清楚随机变量是什么、离散 vs 连续的区别、为什么 3DGS 里处处是概率。  
> **前置知识**：初中数学（集合、函数基本概念）。不需要任何概率基础。  
> **核心问题**：如果你要设计一个系统来模拟"不确定的世界"，你会发明什么数学工具？

---

## 🎯 问题驱动：为什么我们需要随机变量？

### 场景 1：你看不见真实场景

想象你在训练 3DGS。你的相机拍了一张照片——但你知道这张照片是**不完美**的：

```python
# 真实的物理过程：
real_color = perfect_scene + noise(camera_sensors) + lighting_uncertainty
#                        ↑                        ↑
#                    传感器噪声              光照不确定性

# 你观察到的（只有这个）:
observed_pixel = [0.52, 0.31, 0.87]  # RGB，但真实值可能略有不同
```

**关键问题**：你怎么描述这种"不完美"？怎么量化"它可能偏离多少"？

### 答案：随机变量（Random Variable）

一个 **随机变量** 就是"用数学符号表示不确定量的工具"。

- 掷骰子 → `X ∈ {1, 2, 3, 4, 5, 6}` — X 是随机变量
- 相机像素值 → `C ∈ [0, 1]³` — C 也是随机变量（连续型）
- Gaussian Splat 的位置 → `(x, y, z) ~ N(μ, Σ)` — 也是

**本质洞察**：随机变量不是一个具体的数，而是一个**取值规则 + 每个取值的概率**。

---

## 📐 Part 1: 离散 vs 连续 — 两类世界
### 离散型（Discrete）：有限/可数种可能

**直觉引入**：想象你在一个十字路口等红灯。交通灯只有三种状态——红、黄、绿。你无法精确预测下一秒会看到哪个颜色，但可以基于经验知道：红灯约占 60%，绿灯占 30%，黄灯占 10%。**"下一秒看到什么颜色"就是一个离散型随机变量** — 它的可能取值是有限的（3种），且每种都有确定的概率。

再举一个例子：外卖平台上的订单类型。每笔订单要么是"堂食"、"外卖"或"自提"之一。如果你统计了上万条历史数据，发现堂食占 50%、外卖占 35%、自提占 15%，那么随机选取一单，它属于哪类就是一个离散随机变量 — 取值只有 {堂食, 外卖, 自提} 三个，每个有确定的概率。

**定义**：随机变量 X 的可能取值是有限个或可数个。

```
掷硬币:   P(X= heads) = 0.5,  P(X= tails) = 0.5
掷骰子:   P(X=k) = 1/6,  k ∈ {1,...,6}
交通灯:   P(红)=0.6,  P(黄)=0.1,  P(绿)=0.3
3DGS中：  某个像素由第i个Splat贡献 → i ∈ {1,...,N}（离散选择）
```

**概率质量函数 (PMF)** — 给出每个取值的概率。用交通灯的例子来说明：

假设 $X$ = 你看到的交通灯颜色，取值空间 $\{红, 黄, 绿\}$，则 PMF 为：
- $p_X(红) = P(X=红) = 0.6$ — "看到红灯"的概率是 60%
- $p_X(黄) = P(X=黄) = 0.1$ — "看到黄灯"的概率是 10%
- $p_X(绿) = P(X=绿) = 0.3$ — "看到绿灯"的概率是 30%

**概率质量函数 (PMF)** — 给出每个取值的概率：

$$p_X(k) = P(X = k)$$

满足两个条件：
1. **非负性**: $p_X(k) \geq 0$ ∀k
2. **归一化**: $\sum_k p_X(k) = 1$ → $0.6 + 0.1 + 0.3 = 1.0$ ✅

### 连续型（Continuous）：无限多种可能

**直觉引入**：想象你每天早上用手机天气 App 查看气温。App 显示"今天最高温度 23.7°C" — 但实际温度可以在 [0, 50]°C 之间的任意实数值上取值，比如 23.71459...°C。**"今天的温度"就是一个连续型随机变量** — 它的可能取值是无限多的（整个温度区间），无法用 PMF 描述，而需要用一个密度函数来刻画。

再举一个例子：你在跑步时记录的配速。每次跑步的配速可能在 [3:00/km, 8:00/km] 之间的任意值 — 你可以记录到 4分32.567秒每公里，但不可能列出"配速=4分32秒"、"配速=4分33秒"...这些枚举的所有概率。因为取值是连续的无限集，我们需要的是**PDF（概率密度函数）**来描述。

**定义**：随机变量 X 可以在一个区间内取任意实数值。

```
像素亮度:   C ∈ [0, 1]          （可以取 0.31415926...）
今天的温度: T ∈ [-30, 50]°C     （任意实数温度值）
Gaussian位置: μ_x ∈ ℝ³         （任意实数坐标）
Gaussian尺度: Σ ∈ ℝ^{3×3}      （正定矩阵，连续空间）
```

**概率密度函数 (PDF)** — 给出"在某点附近取值的相对可能性"。用气温的例子来理解：

假设今天的气温 $T \sim N(22, 5^2)$（均值 22°C、标准差 5°C），则 PDF 为：
$$f_T(t) = \frac{1}{\sqrt{2\pi \cdot 25}} e^{-\frac{(t-22)^2}{2 \cdot 25}}$$

这个函数在 $t=22$（均值）处取最大值 — 说明温度最可能出现在 22°C 附近。在 $t=37$（远偏离均值）处，PDF 值接近于 0 — 说明几乎不可能达到 37°C。**但注意：PDF 的值本身不是概率！** 它只是"密度" — 就像温度计上某点的温度读数，告诉你这里的"可能性浓度"有多高。
$$f_X(x) \geq 0, \quad \int_{-\infty}^{\infty} f_X(x)\,dx = 1$$

⚠️ **重要区别**（考试必考，实战必踩坑）:

| | 离散型 | 连续型 |
|--|--------|--------|
| 描述工具 | PMF `p(k) = P(X=k)` | PDF `f(x)` — 注意：`P(X=x)=0`！ |
| 概率计算 | 求和 $\sum_k$ | 积分 $\int_a^b f(x)\,dx = P(a \leq X \leq b)$ |
| 归一化条件 | $\sum p(k) = 1$ | $\int f(x)\,dx = 1$ |

**直觉理解 PDF**：PDF 在 x 点的值不是概率，而是"密度"。就像水的密度 — 密度高说明那里水多，但一滴水的重量（概率）需要乘以体积元 $dx$ 才有意义。

## 🔥 Part 2: 从第一性原理推导 — 为什么 PDF 要积分为 1？

### 证明目标

$$\int_{-\infty}^{\infty} f_X(x)\,dx = 1$$

这个等式不是随意规定的，它来自一个基本事实：**世界必须存在某个状态**。

### 推导过程

**Step 1 — 设定公理**：
- 任何事件发生的概率 ≥ 0（非负性）
- 所有可能结果的并集是"必然事件"，其概率 = 1

**Step 2 — 离散→连续过渡**：

考虑掷骰子的 PMF：$P(X=k) = p(k)$。归一化意味着：
$$\sum_{k=1}^{6} p(k) = 1 \quad\text{（所有可能结果加起来是"必然事件"）}$$

现在把骰子变成连续的。想象你有一个精度为 $\Delta x$ 的尺子测长度，把它分成 N 个区间：
$$p_i = P(x \in [x_i, x_i + \Delta x]) \approx f_X(x_i) \cdot \Delta x$$

求和变积分（极限 $\Delta x \to 0, N \to \infty$）：
$$\sum_{i=1}^{N} p_i = \int_{-\infty}^{\infty} f_X(x)\,dx = 1 \quad ∎$$

**工程意义**：PDF 的归一化保证了"世界在某个地方"。如果积分不为 1，说明你的模型要么漏了可能性（< 1），要么多算了不可能的事情（> 1）。

## 🧪 Part 3: 数值示例 — Boxed Result

### 离散案例：模拟 3DGS 中像素来源的随机性

假设场景中有 5 个 Splat，某个像素被第 i 个 Splat 覆盖的概率为：
$$P(\text{pixel来自Splat}_i) = w_i, \quad \sum_{i=1}^5 w_i = 1$$

设定权重：`w = [0.3, 0.25, 0.2, 0.15, 0.1]`

**验证归一化**：
$$\boxed{\sum_{i=1}^{5} w_i = 0.3 + 0.25 + 0.2 + 0.15 + 0.1 = 1.0}$$ ✅

### 连续案例：高斯 PDF 的归一化

标准高斯分布 $X \sim N(0, 1)$ 的 PDF：
$$f_X(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2}$$

**验证**（经典积分，记住结果即可）：
$$\boxed{\int_{-\infty}^{\infty} \frac{1}{\sqrt{2\pi}} e^{-x^2/2}\,dx = 1}$$

这个积分是概率论中最著名的积分之一。推导需要极坐标技巧，但记住：**所有高斯分布的 PDF 都自动归一化** — 这是构造时就保证好的。

## 💻 Part 4: PyTorch 验证 — 从代码理解概念

```python
import torch
import math

# ============================================================
# 1. 离散型：验证 PMF 归一化
# ============================================================
weights = torch.tensor([0.3, 0.25, 0.2, 0.15, 0.1])
print(f"离散PMF求和: {weights.sum().item():.6f}")  # → 1.0

# 模拟采样：掷"骰子"选 Splat
sampled_splats = torch.multinomial(weights, num_samples=1000, replacement=True)
print(f"采样均值（理论期望）: {torch.arange(5).float()[weights].mean():.4f}")

# ============================================================
# 2. 连续型：高斯 PDF 的数值积分验证
# ============================================================
x = torch.linspace(-6, 6, 10000)
mu, sigma = 0.0, 1.0
pdf = (1 / (math.sqrt(2 * math.pi) * sigma)) * \
      torch.exp(-0.5 * ((x - mu) / sigma) ** 2)

# 数值积分（梯形法则）
dx = x[1] - x[0]
integral = pdf.sum() * dx
print(f"高斯PDF数值积分: {integral.item():.6f}")  # → ~1.0000

# ============================================================
# 3. PyTorch 内置验证：用 torch.distributions
# ============================================================
from torch.distributions import Normal, Categorical

normal = Normal(torch.tensor(0.), torch.tensor(1.))
print(f"Normal PDF in [-2, 2]: {normal.log_prob(torch.tensor([2., -2.])).exp().sum():.4f}")

cat = Categorical(weights)
samples = cat.sample((5000,))
print(f"采样频率（理论 vs 实际）:")
for i in range(5):
    actual_freq = (samples == i).float().mean()
    print(f"  Splat {i}: 理论={weights[i]:.2f}, 实际={actual_freq:.3f}")

# ✅ 期望值验证：E[X] = Σ x·p(x)
expected_value = torch.arange(5).float()[weights].sum()
print(f"E[离散随机变量] = {expected_value.item():.4f}（理论: {0*0.3 + 1*0.25 + 2*0.2 + 3*0.15 + 4*0.1:.4f}）")
```

**运行输出预期：**
```
离散PMF求和: 1.000000
高斯PDF数值积分: 1.000000
采样频率（理论 vs 实际）:
  Splat 0: 理论=0.30, 实际≈0.298-0.302
E[离散随机变量] = 1.4500
```

## 🗺️ Part 5: 概率论在 3DGS 里的"藏身之处"

| 概念 | 哪里出现 | 为什么需要它 |
|------|----------|-------------|
| **离散随机变量** | Alpha blending 的顺序（深度排序后的第 i 个 Splat） | 像素颜色 = $\sum_i \alpha_i \prod_{j<i}(1-\alpha_j) c_i$ — 每个Splat的贡献是"依次叠加"的 |
| **连续随机变量** | Gaussian 的参数 μ, Σ | 优化过程中，参数被当作需要从分布中采样的量（正则化、不确定性量化） |
| **PDF + 归一化** | 高斯 Splat 的形状函数 | $\int \mathcal{N}(x; \mu, \Sigma)\,dx = 1$ — 保证能量守恒，不会凭空产生/消失亮度 |

**核心连接**：3DGS 的核心操作（渲染）本质上是在计算一个**随机变量的函数期望**。每个像素是"所有Splat叠加后的结果"——这正是一个连续型随机变量的线性组合。

## 📚 Part 6: 常见分布速查表（离散 vs 连续）

### 离散型

| 分布 | 符号 | PMF | 应用场景 |
|------|------|-----|----------|
| **伯努利** | $X \sim \text{Bern}(p)$ | $P(X=1)=p, P(X=0)=1-p$ | 像素是否被某个Splat覆盖（是/否） |
| **多项式** | $X \sim \text{Mult}(n, p_1,...,p_k)$ | 多项展开系数 | 多个类别的计数 |

### 连续型

| 分布 | 符号 | PDF | 应用场景 |
|------|------|-----|----------|
| **高斯（正态）** | $X \sim N(\mu, \sigma^2)$ | $\frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | **3DGS 的核心！** Splat 的形状就是高斯函数 |
| **均匀分布** | $X \sim U(a,b)$ | $\frac{1}{b-a}$（在[a,b]上） | 初始参数随机化 |

## 🎓 本章小结

### 核心公式

$$\boxed{\text{离散: } \sum_k p(k) = 1, \quad \text{连续: } \int f(x)\,dx = 1}$$

### 关键洞察

> **随机变量不是"随机数"** —— 它是描述不确定性的**完整规则**（所有可能取值 + 各自的概率）。
> 
> **PMF vs PDF 的本质区别**：离散型可以直接问"P(X=5)"，连续型只能问"P(a ≤ X ≤ b)"——因为单点概率为 0。这个区别决定了你能用什么数学工具。
> 
> **3DGS 为什么用高斯？** 因为高斯是"最自然的不确定性建模工具" — 中心极限定理保证大量微小随机效应的叠加趋近高斯分布。

<details>
<summary>💡 提示（点击查看）</summary>
PDF f(x) 是"密度"，不是概率。单点的"体积"为 0，所以概率 = ∫_x^x f(t)dt = 0。就像问"某一点的水的重量" — 没有宽度就没有质量。需要区间才有概率：$P(a \leq X \leq b) = \int_a^b f(x)\,dx$
</details>
